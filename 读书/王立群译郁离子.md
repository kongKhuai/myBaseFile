## 1. 一句话主旨

本书要回答：**"一部以'郁离子'为代言人的古代寓言集，如何借一个个君王、臣僚、商贾、鸟兽与器物的短故事，把乱世处世、治国用民、识人纳言、修身用智的道理讲成可复用的判词？"** 核心答案：以"白话译题〔原篇名〕＋译述＋'郁离子曰'点题＋典故括注"的体例，把六十余篇寓言收束为几条一贯的主张——**重实不重名（取材看质地不问产地）、重诚不重术（假仁义胜于不仁义，德政为本刑法为辅）、知止知返（不轻侮、不轻用兵、不度量力而行）、容众纳言（畏威不如怀德、洞悉利害才能辨忠谀）、专一自省（用智胜用力、大智若愚、心意专一）**。

**区分性**：同为《郁离子》相关读物，校注本重在文字训诂、研究本重在思想体系，本书则**以"译题重标＋篇末点题"把寓言改造成一则则可直接取用的处世判词**；它不追求逐字对译的学术性，而把每篇的"寓意"提到标题位置（"乱世的处世哲学""贿赂失人心，信义方得人""只相信自己的人技穷"），使读者未见故事先见结论。【推断】

## 2. 核心问题链

1. **乱世里君子该如何自处？**——《戚之次且》：郁离子忧世，问难者以孔子"不能推行治世良方却不因烦恼损身"相劝，结论"君子活在世上，只做那些可能做到的事，不做那些不可能做到的事"；吉凶祸福"由上天主管"。（开篇）
2. **向贪君献宝为何反招祸？**——《献马》：芮伯献马于周厉王，芮季劝阻（王欲无厌、近臣索贿），果被诬"藏宝不献"而流放；君子判"芮伯也有错——明知王贪却用好马诱发其贪心"。
3. **取才／取物该以什么为标准？**——《鲁般》《千里马》《枸橼》：修屋看正梁是否朽、"选取材料的时候，只有一个标准，那就是质地优良，而不管它出产自什么地方"；千里马因"非冀北所产"被置最次马房；梁王使者只看枸橼外表"中看不中吃"。
4. **治国靠术还是靠诚？**——《假仁义》"真诚的施行仁义胜过利用仁义，利用仁义又胜过不讲仁义"；《齐伐燕》齐王用田单之策不扰燕民而民心归，却因多疑中苏厉之计扣留降卒家属、纵兵掠夺而尽失民心；《治圃》"只知道征收却不懂得扶持生产"；《畏怀》"怨恨……像火药已经装在炮里，还没有火来引发"。
5. **靠威势还是靠恩德？**——《晋灵公好狗》题下所附"狙公养狙"：小狙一问"山上的果树是狙公种的吗"，群狙悟而携果逃入山林，狙公饿死；点题"只靠耍手段统治百姓……一旦有人启发了他们，那些在上者的手段就将毫无作用"。【推断·标题与正文错位，待核】
6. **轻侮与不自量力有何下场？**——《宋王偃》日日毁谤楚国、群臣附和，华犨谏"军队不能轻易使用，敌人不能一再轻侮""大国戒惧，小国骄傲，危亡的日子大概快要到了"，王怒、次年宋败亡；《城莒》小国要修与大百倍之国同规模的城，"和用小小的羔羊去驾驶象车有什么差别"，五年未成、楚军至而民溃。
7. **人何以被自己所造之物所害？**——《豢龙》以穿山甲为龙、拒谏而杖之，真龙至仍以蚂蚁招待，被雷击死；《茧丝》蚕吐丝自缚，"它之所以招来这场杀身大祸的东西，却是它自己织成并用来保护自身的蚕茧"。
8. **如何辨忠言与谀言？**——《直言谀言》：乌鸦不必有灾、喜鹊不必有喜，而人仍厌乌喜鹊；"正直的规劝……听了以后人们往往是感到不愉快；谄媚的话……最终却不能不受谄言的迷惑"，结论"只有能够洞悉利害的实质，才能辨明人言的忠诚与邪恶"。
9. **智与力、专与杂、明与蔽何者为上？**——《智力》"力量的效应是一，而智慧的效应就是一百"；《大智》"扔掉聪明人的虚名，以愚人的面目出现，却收到聪明人的实际利益"；《一志》"明断产生于心意的专一"；《专心》"心诚就必然明达事理"；《自瞽自聩》《任己者术穷》只信自己则"谋士躲藏起来了……圆滑鄙陋之人却蜂拥而至"。
10. **史书该不该直书过失？**——《论史》：作者认为"以揭发他人的过错、不徇私情，作为史官的一种美好品德实在为后世留下了不少灾难"，举孔子《春秋》"为贤者避讳"、只记齐桓晋文之功，"《尚书》……只记录和颂扬他们的美德，并不记录他们的过失"。【原文·论史；此为其一家之见，见"局限与争议"】
11. **哪些"圣人之制"其实该翻案？**——《七出》：驳"七出"中"重病／不育"两出，"这是后世寡情薄义的男子所说的，并不是圣人的意见"，"后人却把这记下来作为一种必须执行的法令，这实际上是教那些恶人如何害人的方法"。

**逻辑关系**：**并列式寓言＋一贯判词**。各篇独立，但反复回到同一组对立：名／实、诚／术、威／德、力／智、专／杂、忠／谀、止／进。是**归纳式说理**，非体系推演。【推断】

## 4. 中心思想（命题式）

1. **取舍当以"质地"而非"名号／产地／外表"为准，否则必被表象所误**——主张："选取材料的时候，只有一个标准，那就是质地优良，而不管它出产自什么地方"；理由：《千里马》良马因"不是冀北所产"被置最次马房，《枸橼》使者只看果实"又大又漂亮"而不合梁王口味，《豢龙》把穿山甲当龙供养、真龙至仍以蚂蚁招待，《鲁般》"所有的梁都朽烂折断了……已经不能碰了"；限定：这一判词在书中主要用于**识人取物与纳言**，作者并未主张废弃一切名分制度（《赏爵》恰讨论爵位"不能够搞得太滥"的时机问题）。【原文·各篇／推断】
2. **治国以诚为本、以民心为验，权术与威势只能收一时之效且终将反噬**——主张："真诚的施行仁义胜过利用仁义，利用仁义又胜过不讲仁义"，"施行法令是有方法的，那就是推行德政，再用刑法作为辅佐"；理由：《齐伐燕》齐王行田单之策则"燕国百姓……争着归顺齐军"，一因多疑中计扣留降卒家属、纵兵掠夺便"再也不想投靠齐军"；《治圃》"只知道征收却不懂得扶持生产……您的'菜地'已经匮乏了"；《畏怀》"百姓心中的怨恨，就像火药已经装在炮里，还没有火来引发"；狙公"只靠耍手段统治百姓……一旦有人启发了他们，那些在上者的手段就将毫无作用"；限定：作者并不否定刑法与赏罚本身，只反对其脱离德政与诚信而单独使用。【原文·各篇／推断】
3. **轻侮、恃强、不自量力、以欲害身，是同一类"不知止"的败因**——主张："军队不能轻易使用，敌人不能一再轻侮""大国戒惧，小国骄傲，危亡的日子大概快要到了"；理由：《宋王偃》日日毁谤楚国、群臣"如同出自一人之口"地附和，次年"楚国进行反击……最后把宋国也灭亡了"；《城莒》小国"不到人家的百分之一"却要修与绛都同规模的城，"和用小小的羔羊去驾驶象车有什么差别"，五年未完而"满怀怨愤的莒国百姓，没有应战就溃散了"；《献马》芮伯明知王贪仍以好马"诱发他的贪心"；《豢龙》《茧丝》则以"自造之物反害自身"作同型隐喻；限定：这些是**寓言中的因果判词**，不作史实因果的证明。【原文·各篇／推断】
4. **力量不敌智慧，专一胜于多欲，容纳胜于自是；而辨忠谀须先洞悉利害**——主张："力量的效应是一，而智慧的效应就是一百"，"明断产生于心意的专一"，"品德不高尚就不能使人心归附，度量不宏大就不能使人心安定"，"只有能够洞悉利害的实质，才能辨明人言的忠诚与邪恶"；理由：《智力》人"用的是能致虎于死地的器物"；《专心》"知道干旱和水灾的没有人比得过农夫……因为专心"，并以鲁人善讲《易经》而占卜不灵、吴医不善谈脉理而"没有治不好的"作正反例；《德量》"大海并不炫耀自己的博大，正因为它不炫耀……才不停地汇集众流"；《自瞽自聩》《任己者术穷》只信自己则"谋士躲藏起来了，有识之士回避了……圆滑鄙陋之人却蜂拥而至"；《直言谀言》忠言"听了以后人们往往是感到不愉快"、谀言"最终却不能不受……迷惑"，故进忠者"借着利害关系引导他人"；限定：作者把"洞悉利害"作为辨忠谀的**必要**条件而非充分条件，且《七出》《论史》两篇显示他并非一切成制都顺从。【原文·各篇／推断】
5. **"译题＋点题"的今译体例，本身即是一种主张：寓言的价值在可提取的判词，而非故事或训诂**——主张：目录以"乱世的处世哲学""贿赂失人心，信义方得人""只相信自己的人技穷""欲望是人性的大敌"等白话判词重标原篇名；理由：正文多以"郁离子曰"收束并直陈寓意（如《狙公》"大概也都像这位狙公吧"、《惜鹳智》"可悲啊！鹳鸟虽然有智慧，但令人叹惜的是这种才智太有限了"），括注又专司人物、地名、典故的坐标说明；限定：这是**编译者的取舍**，其译题是否准确概括原篇寓意、是否留有原书文意，素材未提供校勘信息，须与底本核对。【推断】

> 说明：以上命题为**从多篇寓言与"郁离子曰"点题中归纳、按"主张＋理由＋限定条件"重组**，非原书逐条列出的纲领，故标【推断】；直接引语标【原文】。

## 5. 内容梗概（古籍今译·寓言说理集，按体例与主题群）

- **体裁判定**：非单线论著，亦非纯虚构小说，而是**寓言政论集的今译**；故不套"问题—方法—证据—结论"的单线论证，也不套单线故事梗概，而按**体例＋主题群＋单篇说理结构**梗概。【推断】
- **体例**：每篇三层——① 双标题（白话译题＋〔原篇名〕）先把寓意前置；② 白话译述一则短寓言，人物多为"作者虚拟的人名"（戚之次且、娅冶子、石羊先生、豢龙先生、须麋、艾大夫、子余、南宫子朝等）与历史人物（周厉王、芮伯、齐湣王、鲁仲连、宋王偃、越王勾践、伍子胥、文种、范蠡、梁王、公仪子、鲁穆公、东陵侯、司马季主、楚昭王、子游、平原君、虞卿等）交错；③ 篇末"郁离子曰"或"君子曰／君子认为"直陈寓意，括注补出人物生卒、地名今释与典籍出处（《诗经》《山海经》《史记》《淮南子》《茅亭客话》《道德经》《战国策》等被引用）。【原文·各篇／推断】
- **主题群**：名实取材（献马、鲁般、千里马、枸橼、豢龙）→ 治国诚术（假仁义、齐伐燕、治圃、畏怀、赏爵、行币有道）→ 君臣知止（越王、宋王偃、城莒、狙公、东陵侯）→ 识人信义（贾人、畏鬼、虞卿谏赏盗、噪虎）→ 物喻处境（九尾狐、鹰化为鸠、象虎、九头鸟、惜鹳智、羹藿）→ 修身用智（智力、大智、良心、德量、专心、一志、自瞽自聩、七出）→ 翻案收束（论史、直言谀言、茧丝）。【推断】
- **单篇说理结构（可复用）**：`设一具体情境（君王／臣僚／商贾／鸟兽） → 有人劝谏或有一问难者 → 当事人不听或一意孤行 → 后果应验（败亡／饿死／见弃／招祸） → "君子曰／郁离子曰"点出判词 → 有时再引一句经典或史实作旁证`。例《献马》：芮伯得良马欲献周厉王 → 芮季劝"王欲无厌、近臣必索贿" → 芮伯不听 → 近臣索贿不得而诬"藏宝不献"、厉王怒而流放 → "君子认为，芮伯在献马的事上也有错误——他明明知道国王贪得无厌，却又用好马来诱发他的贪心"。【原文·献马／推断】
- **解释立场**：**以寓言立判词、以典故作坐标、以"君子曰"收束**，基本不展开义理争辩；对成制偶作翻案（《七出》直斥"打着圣人之言的旗号"，《论史》为"为贤者讳"辩护），显示编译／点题者并非全盘顺从传统。【原文·七出、论史／推断】
- **应用边界**：寓言的因果是**劝喻性的**，不是史实或经验论证；约半数篇目正文材料不足；素材分段存在标题与正文错位；译题为编译者所加，是否贴合底本文意待核。【推断】

## 7. 论证链或叙事线

```
【体例前提】双标题把寓意前置 + "郁离子曰"把寓意收束 + 括注给典故坐标
        ↓
单篇说理结构（归纳式，非演绎）：
 设情境（君王 / 臣僚 / 商贾 / 鸟兽 / 器物）
 → 有劝谏者或问难者（芮季、华犨、正舆、子余、老狈、小狙、戚之次且…）
 → 当事人不听 / 一意孤行 / 被表象所蔽
 → 后果应验（流放、败亡、饿死、见弃、招祸、自缚）
 → "君子曰 / 郁离子曰"点出判词
 → 偶引经典或史实作旁证（《诗经》《史记》《道德经》《山海经》）
        ↓
六组对立贯穿全书：
 名 ↔ 实（献马 / 千里马 / 枸橼 / 豢龙 / 鲁般）
 术 ↔ 诚（假仁义 / 齐伐燕 / 狙公 / 治圃 / 畏怀）
 威 ↔ 德（畏威怀德 / 火药之喻 / 城莒 / 宋王偃）
 力 ↔ 智（智力 / 大智 / 专心 / 一志）
 忠 ↔ 谀（直言谀言 / 噪虎 / 自瞽自聩）
 进 ↔ 止（戚之次且 / 献马 / 豢龙 / 茧丝 / 东陵侯）
        ↓
【翻案与收束】《七出》驳成制、《论史》议史笔、《茧丝》把"自护之物反害"推及天人关系
```

**关键前提**：作者预设"一则短寓言的因果足以支撑一条普遍判词"，即**以事喻理、以果证因**；这是劝喻逻辑，不是可检验的因果论证。【推断】

**关键转折**：几乎每篇的转折点都在"劝谏被拒"与"后果应验"之间；真正的"论证"落在篇末"君子曰"一句，故事只是把判词具象化。【推断】

## 9. 可迁移模型/行动清单

**模型：寓言判词四步法（读一篇，取一条可复用判词）**——① 找"被拒的劝谏"：谁说了什么没被听；② 找"应验的后果"：哪一环节开始失控；③ 抄"篇末点题"：把它改写成一条不含具体人物的判词；④ 加"限定条件"：这条判词在什么情形下不成立。

| 步骤 | 操作 | 判断标准 | 边界 |
|---|---|---|---|
| 1 拆结构 | 情境／劝谏／拒谏／后果／点题五格填表 | 五格是否齐 | 错位篇目先核标题与正文 |
| 2 提判词 | 把"君子曰"改写成通用句 | 能否脱离原人物仍成立 | 判词是劝喻，非定律 |
| 3 找对立 | 归入名实／诚术／威德／力智／忠谀／进止六组之一 | 是否与其他篇互证 | 勿强行归类 |
| 4 加限定 | 追问"何时不该这样" | 能否举出反例 | 例：《赏爵》恰说明"不可太滥"也须看时机 |
| 5 核底本 | 译题是否贴合原篇文意 | 有无校勘信息 | 本书素材未提供，标待核 |

**行动清单**：① 读寓言先跳到篇末"郁离子曰"，再回看故事；② 用"劝谏被拒"清单检查自己做决定时是否只听同声附和（对照《宋王偃》群臣"如同出自一人之口"）；③ 用"质地不问产地"检查评选、招聘、采买中的出身偏见；④ 用"洞悉利害"检查听到的赞美与规劝；⑤ 用"火药之喻"检查团队／关系里"没有怨言"是否只是尚未引发；⑥ 引用译题时注明为编译者所加，宜与底本核对。

## 10. 局限与争议

1. **素材覆盖不足且存在错位**：约半数篇目仅见目录或标题串；"分段要点"中多处标题与所附正文不符（《晋灵公好狗》附狙公故事、《象虎》附齐湣王与石羊先生段、《论史》尾句接《直言谀言》）。本笔记只据可辨正文归类，相关篇目归属标【推断·待核】，不据译题臆补情节。【原文·素材结构／推断】
2. **译题为编译者所加，是否贴合底本待核**："乱世的处世哲学""贿赂失人心，信义方得人""只相信自己的人技穷"等白话判词是**再解读**，可能收窄或偏移原篇寓意；素材未提供底本文字与校勘说明，无法核对。【推断】
3. **原书作者与年代素材未标**：署名仅"王立群译"；【外部通识】《郁离子》一般指明代刘基（刘伯温）所著、郁离子为其托名，但素材包内未直接标注原书作者、成书年代与版本，本笔记不把此背景写作本书事实。【外部通识·待核】
4. **《论史》为一家之见、且可争**：作者认为"以揭发他人的过错、不徇私情，作为史官的一种美好品德实在为后世留下了不少灾难"，并引《春秋》"为贤者避讳"、《尚书》"只记录和颂扬他们的美德，并不记录他们的过失"为据；这与"直书实录"的史学传统相冲突，属**文本中的立场**，本笔记只转述、不作背书。【原文·论史／推断】
5. **性别与制度议题的时代性**：《七出》虽驳斥"重病／不育"两出"太残忍"，称"这是后世寡情薄义的男子所说的，并不是圣人的意见"，但仍以"淫乱、嫉妒、不孝、多言、偷盗五种毛病……赶出家门是应该的"为前提；其翻案是局部的，须放回古典语境理解，不作价值背书。【原文·七出／推断】
6. **寓言因果≠史实因果**：献马、豢龙、狙公、城莒等篇的"劝谏—拒谏—败亡"是劝喻性叙事，所涉人物（周厉王、齐湣王、宋王偃、越王勾践等）与史事按书中转述照录，本笔记未核对正史，不作史实断言。【推断】
7. **括注的可靠性**：括注中大量"作者虚拟的人名""在位××年""今山东××县"等说明，属编译者所加的注释层；其人物生卒、地名今释与典籍引文（《淮南子》《山海经》《茅亭客话》等）未核对版本，页码材料不足。【原文·括注／推断】
8. **阅读局限**：本笔记依据素材包，《戚之次且》《直言谀言》《作茧自缚》《献马》《智力》《大智》《德量》《专心》《一志》《七出》《论史》等可读到较完整段落，其余多为首 260 字＋尾 160 字或仅标题；主题群的划分与命题归纳待补核。——阅读局限声明。

## 13. 三档压缩版

**100 字版**：《王立群译郁离子》是一部古籍今译的寓言说理集：以"白话译题〔原篇名〕"重标六十余篇，正文译述短寓言，篇末以"郁离子曰／君子曰"点出判词，括注补人物、地名与典故坐标。全书借献马、狙公、豢龙、枸橼、千里马、宋王偃、城莒、智力、德量、七出、直言谀言、茧丝等篇，反复判六组对立——名与实、诚与术、威与德、力与智、忠与谀、进与止；结论落在"取材只问质地""德政为本刑法为辅""力量的效应是一，智慧的效应就是一百""洞悉利害才能辨忠谀"。它重可提取的判词，不重训诂或故事。

**300 字版**：本书要回答：一部以"郁离子"为代言人的古代寓言集，如何借君王、臣僚、商贾、鸟兽与器物的短故事，把乱世处世、治国用民、识人纳言、修身用智讲成可复用的判词。编译者王立群采用"双标题＋译述＋点题＋括注"三层体例：目录以"乱世的处世哲学〔戚之次且〕""利用仁义〔假仁义〕""作茧自缚〔茧丝〕"这类白话判词重标原篇名，正文译述寓言，篇末多用"郁离子曰"直陈寓意，括注则标明"作者虚拟的人名"、历史人物生卒、地名今释与典籍出处。可辨认的正文归为六组主题：名实取材（献马芮伯诱王之贪反被流放、朽梁不可修、"取材只问质地不问产地"、千里马因"非冀北所产"见弃、枸橼中看不中吃、以穿山甲为龙）、治国诚术（"真诚的施行仁义胜过利用仁义"、齐伐燕因多疑中计而尽失民心、治圃"只征不扶"、畏怀"怨恨像火药已经装在炮里"）、君臣知止（群狙悟而逃、勾践逼死文种、宋王偃轻侮楚国而亡、莒国"羔羊驾象车"）、识人信义、物喻处境、修身用智（"力量的效应是一，而智慧的效应就是一百"、大智若愚、德量"海不炫耀"、专心"心诚就必然明达事理"），末以《七出》驳成制、《论史》议史笔、《直言谀言》辨忠谀、《茧丝》"自护之物反害"收束。单篇结构稳定：设情境→有劝谏→被拒→后果应验→"君子曰"点题。读时须记：本素材约半数篇目仅见标题、且分段存在标题与正文错位；译题为编译者所加，是否贴合底本待核；寓言因果属劝喻，不作史实或经验论证。

**800 字版**：《王立群译郁离子》署名王立群译，全书约 3.3 万字，目录列约六十篇。它最显眼的特征是**双标题制**：每篇先给一个白话译题，再以方括号保留原篇名——"乱世的处世哲学〔戚之次且〕""献马的智慧〔献马〕""利用仁义〔假仁义〕""治民如种菜〔治圃〕""畏威与怀德〔畏怀〕""贿赂失人心，信义方得人〔贿赂失人心〕""只相信自己的人技穷〔任己者术穷〕""洞察利害才能辨别直言谀言〔直言谀言〕""作茧自缚〔茧丝〕"。译题本身往往就是一句判词，寓意被提到读者未见故事之前。正文是白话译述的一则短寓言，人物分两类：一类是括注反复标明"作者虚拟的人名"的问难者（戚之次且、娅冶子、石羊先生、豢龙先生、须麋、艾大夫、子余、南宫子朝、华犨等），"郁离子"本身亦被注为"虚拟的人名，在本书中，它常常是作者的化身"；另一类是历史人物（周厉王、芮伯、齐湣王、鲁仲连、宋王偃、越王勾践、伍子胥、文种、范蠡、梁王、公仪子、鲁穆公、东陵侯、司马季主、楚昭王、子游、平原君、虞卿等）。括注还承担人物生卒、地名今释与典籍出处（《诗经》《山海经》《史记》《淮南子》《道德经》《战国策》等）。篇末多以"郁离子曰""君子曰／君子认为"一句收束，把故事落为判词。

可辨认正文可归为六组主题。其一是**名实取材**。《献马》里芮伯伐西戎得良马欲献周厉王，芮季劝"国王的欲望永远不会满足，而且又总喜欢听身边小人的谗言"，后果被近臣索贿不得而诬告"藏宝不献"、厉王流放芮伯；判词却落在献者："君子认为，芮伯在献马的事上也有错误——他明明知道国王贪得无厌，却又用好马来诱发他的贪心。"《鲁般》写郁离子见倒塌房屋而哭，因"所有的梁都朽烂折断了……已经不能碰了"，并给出"选取材料的时候，只有一个标准，那就是质地优良，而不管它出产自什么地方"；《千里马》里良马因太仆一句"不是冀北所产的"被置最次马房，南宫子朝以"绀羽之鹊"喻"如今天下不容你，正是因为你不是'幽旻鸟'"；《枸橼》使者只看果实"像西瓜那么大"的外表，中看不中吃；《豢龙》商陵君把鲮鲤（穿山甲）当龙、杖打进言者，真龙降临时仍"取出准备好的大量蚂蚁请龙来吃"，终被雷电击死。

其二是**治国诚术**。《假仁义》借"春秋五霸利用了仁义"之议立"真诚的施行仁义胜过利用仁义，利用仁义又胜过不讲仁义"，并批评今人"在不妨害自己私欲的前提下找上一两条讲仁义的事去做做，目的是为了买个好名声"。《齐伐燕》最见结构：齐王用田单建议"和燕国保持正常的交往，严令禁止侵扰掠夺……这些措施深得燕国百姓的欢心"；苏厉却看准"齐王是一位急功近利而又多所猜忌的人"设谋，齐王中计扣留降卒家属、将士乘机大掠，"燕国百姓于是再也不想投靠齐军了"。《治圃》以种菜喻治民：菜农"整得很肥沃……根据其种植条件，按照时令节气栽种……不伤害蔬菜的根"，而"如今，您的官吏向百姓征取赋税却不遵从一个起码的限度，只知道征收却不懂得扶持生产……您的'菜地'已经匮乏了"。《畏怀》区分"畏威"与"怀德"，留下全书最强比喻："百姓心中的怨恨，就像火药已经装在炮里，还没有火来引发罢了。"《赏爵》《行币有道》则补出分寸："爵位，是君王表彰有功者使用的，不能够搞得太滥"，而"施行法令是有方法的，那就是推行德政，再用刑法作为辅佐"。

其三是**君臣知止**。《宋王偃》"每天早晨上朝，一定要毁谤楚国一番，以此作为笑谈"，群臣"如同出自一人之口"地附和；华犨谏"军队不能轻易使用，敌人不能一再轻侮……如今楚国已经戒惧了，但是您却更加骄傲了。大国戒惧，小国骄傲，危亡的日子大概快要到了"，王怒、华犨逃齐，"第二年，宋国再次攻打楚国，楚国进行反击……最后把宋国也灭亡了"。《城莒》正舆大夫劝"我们小小的莒国，和晋国相比，不到人家的百分之一……这和用小小的羔羊去驾驶象车有什么差别呢"，五年未修完而"楚军打来，满怀怨愤的莒国百姓，没有应战就溃散了"。《越王》里勾践大宴论夫差因杀伍子胥而亡，子余却反揭"现在大王逼死了大夫文种，又迫使范蠡出走……越国已经没有治国的贤才了"。素材中《晋灵公好狗》题下所附实为"狙公养狙"故事：小狙三问（"山上的果树是狙公种的吗""是不是除了狙公，谁都不能上山去采果子了呢"）使群狙醒悟、毁栅携果逃入山林，"狙公最终饿死了"，点题"只靠耍手段统治百姓……一旦有人启发了他们，那些在上者的手段就将毫无作用"——此篇标题与正文错位，归类标【推断·待核】。

其四是**修身用智与翻案**。《智力》"虎用的是力量，而人用的是智慧……所以，力量的效应是一，而智慧的效应就是一百"；《大智》"扔掉聪明人的虚名，以愚人的面目出现，却收到聪明人的实际利益"；《德量》"大海并不炫耀自己的博大，正因为它不炫耀自己的博大，所以才不停地汇集众流"；《专心》以鸮知风、蚁知雨、农夫知旱涝、鲁人善讲《易经》而占卜不灵、吴医"如果和其他医生谈论脉理辨证，他肯定说不过别人"却治病皆愈，归为"心诚就必然明达事理"；《一志》"明断产生于心意的专一"；《自瞽自聩》只信自己则"谋士躲藏起来了，有识之士回避了……圆滑鄙陋之人却蜂拥而至"。《七出》直斥以"重病／不育"出妻是"后世寡情薄义的男子所说的，并不是圣人的意见"，"这实际上是教那些恶人如何害人的方法"。《论史》则主张直书过失"为后世留下了不少灾难"，举《春秋》"为贤者避讳"——此为其一家之见，与直书实录传统相冲突，须标立场。末篇《直言谀言》以乌鸦喜鹊起："正直的规劝……听了以后人们往往是感到不愉快；谄媚的话……最终却不能不受谄言的迷惑"，结论"只有能够洞悉利害的实质，才能辨明人言的忠诚与邪恶"；《茧丝》由蚕"吐丝而织成茧是为了保护自身，最终被人煮茧抽丝害了自己"推及人取万物之辨，收束全书。

读法上有四条边界须守：其一，本素材约半数篇目（八骏、石羊先生、井田可复、行币有道、贿亡、惜鹳智、子侨祸心、蛰父不仕、自瞽自聩、情为欲使、立教、贪利贪德辨、饮漆毒水、止秦伐周、虞卿谏赏盗、噪虎等）仅见标题或标题串，且"分段要点"中多处标题与所附正文错位，本笔记只据可辨正文归类并标待核；其二，译题是编译者所加的再解读，是否贴合底本文意无校勘信息可核；其三，署名仅"王立群译"，素材未直接标注原书作者与年代，【外部通识】所谓《郁离子》为明代刘基所著只作背景提示、不写作本书事实；其四，寓言的"劝谏—拒谏—败亡"是劝喻性因果，不作史实断言，《论史》《七出》的立场亦只转述、不背书。它最可迁移的不是任何一条判词，而是"设情境→劝谏→拒谏→后果→点题"这一可拆解的说理结构，以及给每条判词补上一个限定条件的习惯。
