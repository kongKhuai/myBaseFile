## 1. 一句话主旨

本书要回答：**"既然'存在'问不得、终极真理不可得，那么万物（从奇点、基本粒子、原子分子到生物与人类）为什么仍不断分化、不断复杂化、又不断走向失稳？"** 核心答案：提出一条自命"宰制一切规律的规律"的**递弱代偿衍存法则**——存在并非圆满自足，其本原就带着"存在效价不足"的缺憾；愈后衍的存在者**存在度愈低（愈弱、愈短、依存条件愈繁）**，为免于失存只能以**属性增益与结构复杂化**来"代偿"，而代偿"有效于补助衍存者的弱化续存，无效于补助衍存者的弱化本性"，于是"进化"实为"递弱"，"完善"不过"残弱"的形态，精神、社会与人类危机皆此法则的现象形态。

**区分性**：同为本体论著作，海德格尔追问"存在之意义"、黑格尔以"绝对精神"闭环、达尔文以"适应增强"解释演化，本书则**把"存在"量化为一个可递减的参数（存在度），把"进化"倒转为"递弱"，并以"因即为果、果即为因"的自因决定论收束**；它既不是宇宙论科普、也不是哲学史梳理，而是一套**用自创术语链推演、并处处以括号纠驳前人**的封闭体系。【原文·各章／推断】

## 2. 核心问题链

1. **哲学的第一设问应该是什么？**——不是"存在是什么"，而是"作为存在者的设问者何以要追问存在"；因为"一旦对存在设问，那'存在'已是设问者感知中的主观存在了"。（第一章）
2. **这一设问先天地提示了什么？**——两条公理："存在本身并不牢靠""存在本身并非独立"，因为绝对自足者"无需为存在本身发生疑问／设置对象"。（第二章）
3. **追问者能否跳出逻辑？**——陷入悖论："既不能超脱于逻辑的框范，又必须最终将逻辑置于框范之中"；出路是"从逻辑中的存在找出存在中的逻辑"，即找存在的逻各斯。（第三章）
4. **存在相对于什么而存在？**——"存在只能相对于存在自身而存在，因为存在之外无存在可言"；故"只有存在的相对性……是绝对的"；而"不得不予以追问的'存在'反而问不得"。（第四、六章）
5. **既然问不得"绝对存在"，还能问什么？**——改问"存在的性质／存在之道"，由此引出**存在性**（存在如何可能存在的所以然）与**存在度**（把存在量化）。（第六、七、九章）
6. **存在度如何分布？**——设存在度区间（0，1）；考察紊乱／均等／波动／趋升／趋降五种分布，取"趋降分布"为最本质者，须"追溯到幽远的宇宙源头及其衍存流程"。（第九、十一章）
7. **衍存梯度证实了什么？**——奇点→夸克轻子玻色子→92 种天然元素→上千万种分子物类→数十亿类生物物种→人类；伴随"相对量度递减、相对时度递短、衍存条件递繁"。（第十二、十三章）
8. **分化的动力是什么？**——前体存在"倾向于成全或补偿自身不圆满本性的相对残弱单元"，但"补偿"只能呈现为**分化与再构合**，故"补偿"改称"代偿"。（第十六至十八章）
9. **代偿为何既有效又无效？**——须引出"代偿度"：有效于把弱存者维持在存在阈上，无效于追补已流失的存在效价；"正是由于代偿效价的这种两重性，才有了自然万物的勃勃生机"。（第十九章）
10. **"进化""适应""精神""完善"该如何重解？**——"进化"深藏逐层递弱；"适应性越强的物种其实就是生存度越弱的物种"；虚存（感应／精神属性）压倒实存而成为"伪在／危在"；"完善"与"残弱"等价。（第二十二、二十六至二十八章）
11. **终点是什么？**——"从存在到失存，是物质演化运动不可逆转的唯一走向"；灭归、衰竭、过度代偿；本原"自因"即"物自性"，导致铁一样的决定论，"递弱代偿衍存法则"是"宰制一切规律的规律"。（第二十三、二十四、三十章）

**逻辑关系**：**公理化推演，层层定义**。第一设问 → 两条公理 → 逻辑悖论与出路 → 相对性 → 存在性 → 存在度 → 五种分布 → 衍存梯度（经验印证）→ 分化／代偿 → 代偿两重性 → 属性／结构并行代偿 → 递弱重解进化 → 灭归与衰竭 → 虚存与完善之辨 → 自因决定论收束。是**演绎式体系**，与考据、随笔类完全不同。【推断】

## 4. 中心思想（命题式）

1. **哲学的第一设问须从"存在是什么"改为"设问者何以追问存在"，因为一经设问，存在已是被感知的主观存在**——主张："哲学上所谓的'存在'仅指感知中的对象之总和"，"一旦对存在设问，那'存在'已是设问者感知中的主观存在了"；理由：分辨存在在主观之内或之外"已无意义"，因为分辨前后并无异样，"反正无论如何你只能面对这样一种存在"；限定：作者并未由此取消本体论，而是把追问对象降为"存在的性质／存在之道"，并明确"哲学……决不是有关'终极真理'的学问，反而恰恰是何以不能有终极真理的学问"。【原文·第一、六章】
2. **存在本身不牢靠、不独立，其本原即带"存在效价不足"的缺憾，这是演化的内驱原动力**——主张：两条公理（绝对自足者无需为自身发生疑问／设置对象）＋第八章的两项假设（若效价十足则应永恒不变；若可丢光则应一无所存），故现实存在者"暗含着一个使之难以存在下去的缺憾"；理由：一切具体存在者"终于不免要流逝、变迁、转化、灭归"；限定：作者把这一步明确标为"我们假设"，属**体系公设**而非经验证实，其"证明"是反证式的（若非如此则……），本笔记不为其真实性背书。【原文·第二、八、十六章／推断】
3. **存在度沿衍存序列不可逆地递减，代偿度相应递增；代偿既有效又无效，故"进化"实为"递弱"**——主张："在宇宙存续的演化历程上，存在度作为一个变项势将无可逆转地逐步下滑"，而"愈残者，结构整合的要求愈高……各残体之间内在的相互感应性能也就必须愈为完备"；理由：衍存梯度（奇点→粒子→元素→分子→物种→人类）与"相对量度递减、相对时度递短、衍存条件递繁"三态势；并给出两重性判词："代偿既是有效的，又是无效的，有效于补助衍存者的弱化续存，无效于补助衍存者的弱化本性"；限定：作者自己承认"适者生存"式的表面现象会造成"深层次的盲区"——"生物种系的外在'生存能力'与其内在'生存效力'"须分开，且"适应性越强的物种其实就是指'生存度越弱的物种'"这一倒转是其体系内的重解，非生物学通行结论。【原文·第十三、十八、十九、二十二章／推断】
4. **精神、社会与人类危机不是例外，而是虚存代偿压倒实存的现象形态；"完善"与"残弱"等价**——主张："虚存压倒实存乃是自然实体自身趋于倾圮的产物"，感应／感知属性即"精神存在"，而"他的'完善'与他的'弱质'等价，他的'弱质'又与他的'残质'等价"；理由：第二十六章把智质存在归为"高度发达的属性代偿"，第十二章已把"环境危机、生态危机、人口危机、大规模毁灭性武器危机以及生物技术可能引发的恐怖前景"称作"衍存递弱自然律的现象形态和继续表达"；限定：这一推广在**本素材中只到卷一**，作者明说社会发生、感应属性的详论"详论见于卷二""详见卷三"，故本命题的论证在此并不完整；本笔记只作中性转述，不引申对现实社会的任何评论。【原文·第十二、二十六至二十八章／推断】
5. **万物由"自因／物自性"决定，因即果、果即因，故递弱代偿是"宰制一切规律的规律"**——主张："不是'因'转化为'果'……而是'因'即为'果'，'果'即为'因'"，"自因"一词"终于又不及'自性'（或'物自性'）一词用意确切"；理由：借斯宾诺莎 causa sui 把"一切存在都是被决定的"读为"自己决定自己的'必然'，是为'自由'的必然"，并纠正"果依赖因而因不依赖果"——"正是由于'前因'之不足才导致'后果'来为之代偿"；限定：作者明说此处的"自由"实为谈"必然"，"与后文中之'能动性自由'、'社会性自由'等涉及康德第三组二律背反命题的概念有所不同"，即该决定论只在特定论域内成立。【原文·第三十章】

> 说明：以上 5 条系**按"主张＋理由＋限定条件"重组**的体系命题；作者原文多用"我们假设""由此可见""由此达成"等推演句，凡此均标【推断】以提示为重构，直接引语标【原文】。

## 5. 内容梗概（非虚构·理论，全书论证梗概）

- **问题**：存在问不得、终极真理不可得，那么万物为何不断分化、复杂化又不断失稳？"为什么一切存在者——包括人类本身在内——非要如此这般的存在不可？"
- **方法**：**公理化定义链推演**。操作依次为：改换设问 → 立非逻辑直证的两条公理 → 处理"以逻辑追问逻辑"的悖论 → 立存在相对性 → 逐级定义"存在性→存在效价→存在度→代偿度→物自性" → 设五种可能分布并取"趋降" → 用衍存梯度作博物学印证 → 推演分化／代偿／属性结构并行／衰竭／灭归 → 收束于自因决定论。每一章几乎都以"由此达成""是为""换言之"推进，并以【】括注纠驳哲学史与指引卷二卷三。【推断】
- **证据**：① 哲学史文本（老子"反者道之动"、"有生于无"，巴门尼德"存在是一"，亚里士多德《形而上学》"起于惊异"，斯宾诺莎 causa sui，莱布尼茨单子，康德四组二律背反，黑格尔《小逻辑》，海德格尔"从在者中引申不出在"）；② 现代科学与博物学尺度（宇宙奇点、哈勃望远镜与宇宙常数、暗物质暗能量、霍金《时间简史》、92 种天然元素、元素周期表、夸克与电子、蓝绿藻与恐龙、盖尔曼《夸克与美洲豹》）；③ 概念内部的反证式推理。三类证据的作用是**为已立的公设提供印证与对话对象**，而非归纳出公设。【原文·各章／推断】
- **结论**：递弱代偿衍存法则——存在度递降、代偿度递增、属性与结构并行复杂化、演化不可逆、终点为灭归与衰竭；"进化"重解为"递弱"、"适应"重解为"生存度弱"、"完善"重解为"残弱之形态"、精神重解为"虚存代偿"；最终"自然存在'决定'让自身继续存在下去这样一个简单的规定"即是宰制一切规律的规律。【原文·第三十章／推断】
- **解释立场**：**强体系、强还原、强批判**。作者把前人（海德格尔、黑格尔、老子、尼采、达尔文式进化观）一律读作"未明此理"的注脚，且自认本卷可命题为"形而下学"；同时反复自设限定（"也许，将存在度区间设定为（0，-1）才显得更精确……乃是取其比较符合常理、比较简易、也比较清晰的优点"），显示其对参数选择的人为性有自觉。【原文·第九、二十二章／推断】
- **应用边界**：这是**卷一／节选的骨架**，卷二（感应属性、认识论）与卷三（社会发生）未纳入；公设不可证伪、科学数据未核对、自创术语不可与通行学科术语直接对应；适合作为"一套自洽的思辨模型"来读，不宜当作物理学或生物学结论。【推断】

## 7. 论证链或叙事线

```
【改设问】存在＝感知中对象之总和 → 一经设问即主观存在 → 问"设问者何以要问"
 → 【公理】A 存在不牢靠 / B 存在不独立（绝对者无需自问、无需设对象）
 → 【悖论与出路】以逻辑追问逻辑 → 必须"从逻辑中的存在找出存在中的逻辑"
 → 【相对性】存在只能相对于存在自身 → "只有相对性是绝对的"
 → 【转向】"不得不问的存在反而问不得" → 不问绝对存在，改问"存在的性质"
 → 【定义链】存在性 → 存在效价（本原即不足） → 存在度（0，1）
 → 【分布】两项定理（总体守恒／个别流变）→ 五种分布 → 取"趋降"
 → 【印证】衍存梯度 + 递弱三态势（量减 / 时短 / 条件繁）
 → 【动力】残弱单元 → 补偿 → 但本原之外无他物，故补偿＝分化与再构合 → 改称"代偿"
 → 【两重性】代偿度：有效于续存、无效于补本性 → "由此达成递弱代偿的自然原理"
 → 【机制】属性与结构并行代偿；活跃／动荡为反向、同向指标
 → 【重解】进化＝递弱；适应强＝生存度弱；虚存＝精神；完善＝残弱；简约＝本原强
 → 【终点】过度代偿 / 失代偿 / 衰竭 → 灭归（不可逆）→ "从存在到失存……唯一走向"
 → 【封顶】自因＝物自性，因即果、果即因 → 决定论
 → "递弱代偿衍存法则……宰制一切规律的规律"【收束】
```

**关键前提（须显式标注）**：① 存在可被量化为单一参数"存在度"；② 本原存在自带"效价不足"（作者明标"我们假设"）；③ 衍存梯度的先后顺序可解释为存在度递减；④ 一切属性（含精神、社会）皆代偿产物。四条均为**体系公设**，作者以反证与博物学尺度印证，但未提供可检验的独立判据。【推断】

**关键转折**：第十七章"补偿只能呈现为分化"把"补足"倒转为"自残之后的自救"，第十八章据此把"补偿"改称"代偿"，第十九章再以"既有效又无效"化解矛盾——这三步是全书的枢纽。【原文·第十七至十九章／推断】

## 9. 可迁移模型/行动清单

**模型：递弱代偿四问法（作为"读体系／看复杂化"的分析框架，不作事实结论）**——观察任何不断复杂化的系统（技术栈、组织、产品、概念体系）时问：① 它的"存在度"是否在下降（更依赖更多条件、更短的稳定期、覆盖规模更小）？② 新增的功能／层级是"补足了本性"还是只"维持了续存"（代偿的两重性）？③ 属性与结构是不是在并行膨胀（愈残者结构愈复杂、感应配置愈完备）？④ 有没有把"复杂／完善"误读成"更强"，而忽略它可能是"残弱之形态"？

| 步骤 | 操作 | 判断标准 | 边界 |
|---|---|---|---|
| 1 立参数 | 给系统设一个可比较的"自足程度" | 能否说出"它更依赖什么" | 参数不可直接测量，仅作类比 |
| 2 分两重性 | 把每项新增能力归入"维持续存"或"补足本性" | 若只属前者，即为代偿 | 不要预设"复杂＝进步" |
| 3 查并行膨胀 | 看结构层级与信息／感应属性是否同步增长 | 是否愈补愈繁、愈繁愈需再补 | 警惕过度代偿／失代偿 |
| 4 复核前提 | 追问"公设是什么、能否证伪" | 是否把类比当成了因果律 | 体系自洽 ≠ 事实为真 |
| 5 留缺口 | 标明哪些论证在别卷／别处 | 是否诚实标"材料不足" | 不以局部推全书 |

**行动清单**：① 读任何自创术语密集的理论书，先做"术语—定义—公设"三栏表；② 区分"作者用反证法立的公设"与"作者引科学作的印证"；③ 遇到"由此达成""宰制一切"式封顶句，回头核对其前提是否可独立检验；④ 用"活跃／动荡是存在程度的反向指标"检查自己是否把"繁忙"误当"强健"；⑤ 引用本书时务必注明"仅卷一／节选，卷二卷三未见"；⑥ 不把书中各类危机的哲学表述引申为对现实社会的评论。

## 13. 三档压缩版

**100 字版**：子非鱼《物演通论》（本素材仅第一卷三十章）是一套公理化推演的自然哲学：把哲学第一设问改为"设问者何以追问存在"，立"存在不牢靠、不独立"两公理，定义存在性、存在效价与存在度（0，1），取衍存序列的"趋降分布"，以奇点→粒子→元素→分子→物种→人类之梯度印证"量减、时短、条件繁"，再逼出"补偿只能呈现为分化"、改称"代偿"，并判代偿"有效于续存、无效于补本性"，于是"进化"重解为"递弱"、精神为虚存、"完善"为残弱之形态，末以"自因／物自性"的决定论封顶为"宰制一切规律的规律"。

**300 字版**：本书要回答：存在问不得、终极真理不可得，万物为何仍不断分化、复杂化又不断失稳。作者署「子非鱼」，以自创术语链作公理化推演。起点是改换第一设问——"作为存在者的设问者何以要追问存在"，因为一经设问，存在已是被感知的主观存在；继立两条非逻辑直证的公理（存在本身不牢靠、并非独立），处理"以逻辑追问逻辑"的悖论，立"存在只能相对于存在自身而存在"，再断言"不得不予以追问的'存在'反而问不得"，于是把研究对象从绝对存在降为"存在的性质"。定义链层层推进：存在性 → 存在效价（本原即自带不足）→ 存在度（0，1）→ 五种分布取"趋降"→ 衍存梯度（奇点、基本粒子、92 元素、上千万分子物类、数十亿物种、人类）与"相对量度递减、相对时度递短、衍存条件递繁"三态势。动力机制上，残弱单元要补偿自身，但本原之外全无他物，故"补偿只能呈现为分化与再构合"，遂改称"代偿"；第十九章以"代偿既有效又无效——有效于补助衍存者的弱化续存，无效于补助衍存者的弱化本性"化解矛盾，达成"递弱代偿的自然原理"。由此重解诸概念："进化"实为逐层递弱、"适应性越强"即"生存度越弱"、感应／精神是"虚存压倒实存"、"完善"与"残弱"等价、终点为"衰竭／灭归"且演化不可逆；末章借斯宾诺莎"自因"作"因即为果，果即为因"的物自性决定论，封顶为"宰制一切规律的规律"。读时须记三条边界：本素材仅卷一，卷二（感应属性）卷三（社会发生）材料不足；存在效价、存在度、本原之不足均为作者明标"我们假设"的公设；所引宇宙学与生物学数据未核对，不作背书。

**800 字版**：《物演通论》署名「子非鱼」，是一部以自创术语链推演的哲学理论著作。本素材包标全文约 3 万字、目录为第一章至第三十章，但文中反复出现"详论见于卷二""卷三再谈""（详见卷二）""本卷第五十四章"等括注，可见它只是全书**第一卷（自然哲学，作者自称可命题为"形而下学"）**的论证，另有卷二论感应属性／认识论、卷三论社会发生与人类衍存，本笔记无法覆盖。文体亦特别：正文是定义与推演，方括号【】内是哲学史评议、自我限定与卷际指引，二者须分开读。

第一卷的推演从"改设问"开始。第一章开宗明义："哲学上所谓的'存在'仅指感知中的对象之总和"，并纠正"在者集合成了在"的通常理解——"不是在者集合成了在，而是在分化出了在者"；海德格尔说"从在者中引申不出在"是对的，但"由于他不明白从在如何引申出在者，结果导致他的'此在'及其'澄明的临场'都不免陷入了无来由的黑暗背景中"。作者接着指出，一旦对存在设问，"那'存在'已是设问者感知中的主观存在了"，分辨它在主观之内还是之外已无意义，故"哲学上的第一设问或设问前的潜在疑问应该是：作为存在者的设问者何以要追问存在？"第二章由此立两条无需推论的"公理"：A"存在本身并不牢靠，因为绝对的存在或存在者无需为存在本身发生疑问"；B"存在本身并非独立，因为绝对的存在或存在者无需为存在自身设置对象"；并把"我思故我在"改写为"我思故他在，他在故我思"，连"故"字都可换成"即"。第三章处理"追问者只能从逻辑出发、又必须把逻辑置于框范之中"的悖论，出路是"从逻辑中的存在找出存在中的逻辑，即找出存在自身的逻各斯"。第四章立相对性："存在只能相对于存在自身而存在，因为存在之外无存在可言"，引巴门尼德"存在是一"与老子"道生一，一生二，二生三，三生万物"，得出"只有存在的相对性或相对性的存在是绝对的……但不是存在的根源"。第五、六章清理哲学史：泰勒斯"水为万物之原"、赫拉克利特"火"、柏拉图"理念分有"皆被判为"一团迷惘"，"海德格尔倡导……返回到古希腊的源头去追寻存在，非但无济于事"；继而点出全书最锋利的一句——"不得不予以追问的'存在'反而问不得"，"哲学虽然表现为是究诘'终极原因'的学问，却决不是有关'终极真理'的学问，反而恰恰是何以不能有终极真理的学问"，于是转向"存在的性质／存在之道"，引出第七章的"存在性"（"存在的元质规定性，它使存在得以循序展开"）。

第八章起进入参数化推演。作者明标"我们假设"：本原存在"一开始就有一个自身存在效价不足的本性与存在同在"——若效价十足则应绝对稳定，然而"任何一个具体的存在者终于不免要流逝、变迁、转化、灭归"；又假设后衍存在不会把效价丢光，否则不会"转化保留"。存在效价被定义为"一切存在者的可存在程度的内在指标"，第九章改称"存在度"，设绝对稳定为 1、绝对失稳为 0，现实存在度落在（0，1）；作者自注"也许，将存在度区间设定为（0，-1）才显得更精确"，取（0，1）只因"比较符合常理、比较简易、也比较清晰"。第十章配两项定理（抽象总体存在不灭守恒／具体个别存在相对自逝流变）引出"总体存在效价在具体存在者之间如何分布"，第十一章列紊乱、均等、波动、趋升、趋降五种可能而取"趋降分布"，并说"为此必须追溯到幽远的宇宙源头及其衍存流程中去"。第十二、十三章给出印证：衍存梯度由"奇点"经夸克轻子玻色子、92 种天然元素、上千万种分子物类、数十亿类生物物种到人类（配"衍存梯度示意图"与倒置的"宇宙物演分化进程示意图"），提炼为"相对量度递减、相对时度递短、衍存条件递繁"三态势，断言"存在效价呈现为分度递降的必然趋势无疑具有最根本的确证性"。第十四章特意澄清勿把"时度／量度"误解为单体寿限——"有些单个基本粒子的闪现仅为百亿分之一秒……但它们作为一个自然物类的'存在形式'却分别保持了物理学上最坚韧的上百亿年"。第十五章以老子"反者道之动"与黑格尔辩证逻辑划界："辩证逻辑仅是理性逻辑的低级阶段与初始形态"，老子相信"返回到'结绳而用'的原始生存状态是可能的"正因不能超脱此束缚。

第十六至二十一章是全书的枢纽。前体存在被定义为"倾向于成全或补偿自身不圆满本性的相对残弱单元"，最高存在度即后续存续的"最低阈限或存在阈"，"追求成全或补偿自身本质性不足的自发倾向就构成'演化'或'发展'的内驱原动力"。第十七章关键转折：本原之外全无其他存在，故"所谓'补偿'反而只能呈现为分化的过程，以及分化之后再构合的过程"，"包括人类在内的一切自然分化产物都是自然存在本身的需要……而不是相反——好像'万物皆备于我'，好像'人是万物的尺度'"。第十八章据此把"补偿"改称"代偿"，因为新层位"势必要将存在宿性中的缺陷以某种转化形式重复表达出来，甚至使之获得更趋昭彰和放大的效果"，"由此达成递弱代偿的创世法则"。第十九章引入"代偿度"化解"无效代偿又必须有效"的矛盾，给出全书最精巧的判词："代偿既是有效的，又是无效的，有效于补助衍存者的弱化续存，无效于补助衍存者的弱化本性。正是由于代偿效价的这种两重性，才有了自然万物的勃勃生机。"第二十、二十一章补机制："假如没有下位存在的缺憾，上位存在就无由发生"，属性与结构并行代偿；"活跃程度是存在程度的反向指标""动荡程度是代偿程度的同向指标"。

后段是重解与封顶。第二十二章直指"所谓'进化'或'发展'……深藏着一个逐层递弱的内在趋势，这与'进化论'的固有概念大相径庭"，并把"适应性越强的物种"重解为"生存度越弱的物种"，收于"无知便是美德""智者多忧"；第二十三、二十四章讲过度代偿／失代偿／衰竭与"灭归"（向较低层位回归，是"演化的临时告竭"而非转向），断"从存在到失存，是物质演化运动不可逆转的唯一走向"。第二十五至二十八章把莱布尼茨"单子的原存／预定和谐"接过来，提出"虚存压倒实存……是为生物的智质存在或曰'精神存在'"，"伪在／危在"并非不真实而是实在正失去坚实性；到第二十八章，追问存在方能存在的自觉存在者出现，"他的'完善'与他的'弱质'等价……所谓'完善'不外乎是'残弱'的形态"，尼采"超人"论与亚里士多德"主善"论被判为物自性之继续贯彻。第二十九章以"简单就是坚实……最高的美"与奥卡姆剃刀补证本原之强。第三十章收束：第一因是"自身永远最显完善的缺憾"，"因即为果，果即为因"，"自因"不如"物自性"确切；借斯宾诺莎 causa sui 把"自己由自己的必然"读为决定论——"自然存在'决定'让自身继续存在下去这样一个简单的规定"，终句为"这就是递弱代偿衍存法则的严峻性所在——一个彻底立足于存在的规律……因而是宰制一切规律的规律"。

读法上须守四条边界：其一，本素材仅卷一，卷二卷三材料不足，命题中关于精神与社会的推广在此论证未完；其二，"本原自带不足""存在度区间"等均为作者明标"我们假设"的公设，其证明多为反证式，不构成可检验的经验命题；其三，所引宇宙"150 亿年"、暗物质估计、霍金《时间简史》页码、92 种天然元素等按素材照录，未核对版本，不作背书，"适应性越强＝生存度越弱"亦不可与生物学"适应度"直接对译；其四，作者对海德格尔、黑格尔、老子、尼采的裁断以本体系为准绳，本笔记只标为"作者认为"。它最值得迁移的不是结论，而是那套"术语—定义—公设—复核前提"的读法，以及第十七至十九章"补偿→分化→代偿→两重性"的三步转折。
