## 1. 一句话主旨

本书要回答：**被民间传说与影视作品包裹成「黑暗武士／幻术士」的忍者，在真实历史中究竟是怎样一群人、从怎样的社会结构中产生、又为何在天下统一后消失？** 核心答案：忍者「最初的本质，就是不隶属于任何一个领主的地方武士小集团联盟」——伊贺源于「恶党」、甲贺源于修验道场与林业集团，因两地「没有一个可以……让忍者集团投靠其麾下的大领主」而得以自立；在被织田信长以「天正伊贺之乱」摧毁、又被德川幕府收编为警卫之后，随太平盛世而被淡忘，其形象则被《立川文库》等大众文学重塑为「梦中的忍者」。

**区分性**：这不是忍术教程、不是忍者题材小说、也不是泛谈日本武士文化的通识书，而是**以伊贺、甲贺两大集团为轴，按「地理—政治—组织—人物列传—器物—虚构形象」层层剥去神秘色彩的考据性读物**；它最鲜明的动作是**把「忍者」还原为「地方武士」**，并专设「梦中的忍者」一章说明猿飞佐助等形象「在说书人的团扇里被推出来的英雄」。同类书多重「术」与「传奇」，本书重「社会出身」与「史料可信度」。【推断】

## 2. 核心问题链

1. **忍者为何显得神秘，两大圣地为何是伊贺与甲贺？**——「忍者，这个日本历史上著名的武装团体，一直以来在民间传说及文学作品中都带有极其浓重的神秘色彩」；伊贺「离京都只有八十公里……除了翻越山口进入之外，再无他路可通」，甲贺「地势开阔，北临琵琶湖，几乎与近畿以东的各国道路全都相通」。（伊贺、甲贺与忍者(1)）
2. **地理与技能是决定因素吗？**——不是。「除了上述地理和技能上的原因……最重要的一点其实是政治原因：在这两地，没有一个可以与这些地方势力集团实力相当的、能让忍者集团投靠其麾下的大领主。」（开篇·转折句）
3. **伊贺忍者从何而来？**——「其中的伊贺忍者，其实是从所谓的『恶党』演变而来的」；「恶党」指「从镰仓幕府后期到南北朝期间一直为统治者所镇压的地方武装势力以及零散的武装农民」；楠木正成被称为「恶党」，伊贺「恶党」后担任吉野皇宫警卫，「终于成了名正言顺的武士集团」。（伊贺忍者崛起）
4. **甲贺忍者从何而来？**——「被大多数人接受的，乃是甲贺忍者是由修验道场产生的说法」：饭道山为山岳信仰灵地，开山者相传为役行者（役小角）；修验者「住在山麓娶妻生子……把修验中获得的知识渗透到农村，也走上了地方武士的道路」，「多数人以祈祷、卖药为生……被认为是最后形成忍者军团的核心人士」。（甲贺忍者的祖师）
5. **他们如何组织起来？**——伊贺以族为单位建「惣村」，「不隶属于任何领主，都是自主管理、自主防卫」，共同制定文字条约缔结「伊贺惣国一揆」；甲贺则形成「同名中惣」与「甲贺郡中惣」的「地方小领主联合体」，「并不是一个全员一致的统一联盟，而是一个各自具有一定自主性的联盟」；「上忍」为技术指导者与领袖，「下忍」为具体行动者。（忍者联盟的形成／钩之阵）
6. **为什么没有「以下犯上」？**——「战国时代是一个普遍以下犯上的时期，但是在甲贺却没有以下犯上的现象出现」「一是因为他们的实力都在伯仲之间，没有绝对可以凌驾于他人之上者」。（金句/转折句）
7. **他们如何被摧毁？**——织田信雄两次贸然进攻伊贺均被击退，使伊贺忍者「开始认为『信长并不像人们说的那样强大』，所以对织田信长掉以轻心」；天正九年信长亲率大军，「六天内伊贺的大部分区域为信长军所控制」，柏原城寨坚持到十二月二十八日；且「在与织田信长大战的天正伊贺之乱中，伊贺的忍者们也绝不是团结一致的」。（忍者联盟的消亡／由于信长，伊贺忍者解体）
8. **之后去了哪里？**——「只有少数运气很好的忍者由于自己的技艺而被武家招致麾下，其他多数成为普通农民，少数人则成为盗贼」；德川家康时代仍服务，江户时代负责参勤换防的护卫、保密与江户城「大手三门」警卫；伏见笼城战后甲贺组获俸禄，但「随着时局逐渐太平，忍者……被淡忘了」，「岛原之乱，是忍者们大活跃的最后舞台」。（金句／山冈景友／大原数马／望月兵太夫）
9. **那么「飞檐走壁的忍者」从哪来？**——猿飞佐助「与真田氏有关的正史自不待言，在《真田三代记》中也见不到」，是「在说书人的团扇里被推出来的英雄」，经《立川文库》放大；「真田十勇士」几乎都是「倾慕真田幸村的人们创造出来的人物」，其中寄寓「大阪人意识」与「对江户文化的反抗思想风潮」。（梦中的忍者／佐助诞生）
10. **真实的装束与器具又是什么？**——「要在别人不知不觉的情况下进行谍报活动，最重要的就是打扮得跟普通人没有区别」；「一身黑」不实，「在黑暗里一身黑色打扮反而更加醒目」，故用茶色、烂柿子色、紫蓝色，雪地用白；「忍者是把谍报活动作为自己的主要本领，而不是重要的战斗力量」，故除大规模打斗外不穿锁子甲；「忍者六具」为草笠、三尺手巾、钩绳、打竹、石笔、药品。（装束和常携用具）

**逻辑关系**：从「去神秘化」的设问 → 立**政治原因**为第一因 → 分述伊贺（恶党）与甲贺（修验道/林业）两条发生学路径 → 上升到**组织形态**（惣村／一揆／中惣／上忍下忍） → 用与信长的冲突解释**消亡** → 用江户收编与太平解释**淡忘** → 反过来用《立川文库》解释**传说形象的诞生** → 最后以器物考证回到「谍报者」本色。是**发生学＋消亡史＋形象批判**三段式，人物列传是插入其中的证据串。【推断】

## 4. 中心思想（命题式）

1. **忍者兴起的第一因是政治真空，而非地理或秘术**——主张：「忍者集团最初的本质，就是不隶属于任何一个领主的地方武士小集团联盟」；理由：伊贺与甲贺地形截然相反（一为「隐秘之国」，一为四通八达），却都因「没有一个可以与这些地方势力集团实力相当的、能让忍者集团投靠其麾下的大领主」而生成自治武装；庄园归属复杂（东大寺、京都神社佛寺、摄政关白家领有）使支配力稀薄。限定：作者并未否定地理与技能的作用，明说「除了上述地理和技能上的原因……最重要的一点其实是政治原因」，即**政治是主导变量而非唯一变量**；且「被大多数人接受的」甲贺起源说本身带保留语气。【原文·开篇/甲贺祖师；限定为推断】

2. **伊贺与甲贺是两条不同的发生学路径，殊途而同归**——主张：伊贺由「恶党」演变、甲贺由修验道场与林业集团演变；理由：伊贺「恶党」在长期战斗中形成「与武士的战斗风格有明显的不同」的独特战法、夺取年贡储于村落并产生村落守护体制，「脱去了『恶党』的外衣，开始获得了地方武士的地位」；甲贺修验者「住在山麓娶妻生子……把修验中获得的知识渗透到农村」，「多数人以祈祷、卖药为生」，成为「最后形成忍者军团的核心人士」。限定：两条路径的证据强度不同——伊贺有楠木正成、吉野皇宫警卫等具体人事，甲贺之说标为「被大多数人接受的」且含「相传」「据说」「推定」等语，作者自己对加藤段藏出身亦明说「关于他的出身有很多谜团，并没有定说」。【原文·伊贺崛起/甲贺祖师/加藤段藏；限定为推断】

3. **自治联盟的组织形态（实力均势＋横向联合）既成就忍者，也限制了忍者**——主张：两地都以「各自具有一定自主性」的联盟而非统一体存在；理由：伊贺「惣村不隶属于任何领主，都是自主管理、自主防卫」，由集团共同制定条约结成「伊贺惣国一揆」；甲贺形成「同名中惣」「甲贺郡中惣」；甲贺「没有以下犯上的现象出现」，因「实力都在伯仲之间，没有绝对可以凌驾于他人之上者」。限定：恰恰是这种松散结构与利益本位，使面对外敌时无法一致——「在与织田信长大战的天正伊贺之乱中，伊贺的忍者们也绝不是团结一致的」「其实只要自己的利益能够得到保证，上面的人是谁他们是不怎么在意的」；即**优势与弱点同源**。【原文·忍者联盟的形成/钩之阵/消亡】

4. **忍者的消亡是「乱世→治世」的结构性结果，而非技艺失传**——主张：天下统一后忍者失去存在条件；理由：「在信长、秀吉、家康将世界由乱世向治世推进的过程中，只有少数运气很好的忍者由于自己的技艺而被武家招致麾下，其他多数成为普通农民，少数人则成为盗贼」；江户时代虽仍负责「将军和各大名之间定期换防的护卫、保密」与「大手三门」警卫，但「随着时局逐渐太平，忍者……被淡忘了」，「岛原之乱，是忍者们大活跃的最后舞台」；伏见笼城战后人向幕府「叹请复兴忍术」，得到的是「希望能稍等一段时间」与「银钱五枚」。限定：作者指出「忍者们的生存能力很强……在太平盛世中，他们依然顽强地生存了下来」，即**消亡的是「作为军事职能的忍者」，不是人群本身**。【原文·金句/山冈景友/大原数马/望月兵太夫/忍者联盟的消亡】

5. **流行文化中的「忍者」是后世文学虚构，须与信史分层处理**——主张：猿飞佐助等形象出自说书与《立川文库》，而非史实；理由：「令人遗憾的是他的名字，与真田氏有关的正史自不待言，在《真田三代记》中也见不到」「可以说他是在说书人的团扇里被推出来的英雄，随着说书人的渲染逐渐被夸大，然后又变成了俨然如事实一般的英雄」；「真田十勇士」「几乎都是倾慕真田幸村的人们创造出来的人物」，其背后是「大阪人意识」与「没有一点礼赞德川（家康）的影子」的「对江户文化的反抗思想风潮」。限定：作者并不否定虚构的价值，明说「在这些作品中，时代的形势和大众的愿望复杂交织，使得忍者的形象大为改变。这种虚构的形象，应该是可以原谅的吧」；且对石川五右卫门作了更细的分层——「关于石川五右卫门的情况，人们对其出生和生涯都一无所知，但是由于这次处刑的记载，可以确定历史上实有其人。不过，在这里我们看到的石川五右卫门并不是一名忍者，而是盗贼」。【原文·梦中的忍者/镬刑确实曾经存在】

## 5. 内容梗概（非虚构·历史考据）

- **问题**：忍者为何被视为「带有极其浓重的神秘色彩」的「黑暗武士」？这群人在真实历史中的社会出身、组织方式、活动范围与消亡原因是什么？传说与史实如何区分？
- **方法**：**「以社会结构解释群体，以文献判定真伪」**。前者用地理、庄园归属、领主缺位、年贡、村落共同体、上忍/下忍分工等结构要素解释忍者的产生与形态；后者对每一人物标明所据文献与可信度——可确证（石川五右卫门因处刑记载「实有其人」）、有异说（在敢国神社袭击信长的是三人还是另三人，「到了今天，其真伪已不得而知」）、纯属虚构（猿飞佐助「在《真田三代记》中也见不到」）；并引《万川集海》《伊乱记》《信长公记》《正忍记》等忍术秘传书与古记录，佐以注释、系图、司马辽太郎小说与近人研究。【原文；方法命名为推断】
- **脉络**：伊贺、甲贺地理与政治前提 → 伊贺「恶党」系（楠木正成、吉野皇宫警卫）／甲贺修验道系（役行者、饭道山、杣五家） → 钩之阵与庄园领主衰落 → 惣村、一揆、中惣、上忍下忍 → 织田信雄两败与天正伊贺之乱 → 人物列传（狙击、拔刀、幻术、盗贼、转仕、笼城） → 德川收编与岛原之乱收尾 → 《立川文库》造英雄 → 装束与忍器考证。
- **因果**：领主缺位＋庄园复杂＋山地/林业/修验技能 → 自治武装；实力均势 → 横向联盟（而非统一指挥）；两次击退信雄 → 轻敌；信长亲征 → 联盟解体；乱世终结 → 军事职能消失、多数归农、少数为盗、部分收编；太平＋大众文学 → 形象神秘化。
- **解释立场**：**去神秘化的社会史立场＋对虚构的宽容**。一方面反复用「实际上」「其实是」「非常片面」「真伪已不得而知」纠偏，另一方面承认「这种虚构的形象，应该是可以原谅的吧」，并解释其背后的地域文化心理。【原文·金句/梦中的忍者；概括为推断】
- **应用边界**：一是书中所引古文献、年代、人物均按作者转述记录，本笔记未独立核对；二是「被大多数人接受」「据说」「笔者推定」等处作者已自标不确定，不能当作定论；三是器物部分（忍器、忍法）多引自秘传书，其「有没有效果」作者自己也设问「『水云』等，名字颇为人所知，但是到底使用上有没有效果呢？」；四是中后段忍器与注释仅见标题，未逐段精读。【推断】

## 7. 论证链或叙事线

```
【设问】忍者为何被神秘化？两大圣地为何是伊贺、甲贺？
 → 【立第一因】地理与技能是条件，但「最重要的一点其实是政治原因」＝无实力相当的大领主可投靠
 → 【路径一·伊贺】恶党（地方武装／武装农民）→ 独特战法、夺年贡储村、村落守护体制 → 楠木正成、吉野皇宫警卫 → 转正为武士集团
 → 【路径二·甲贺】修验道场／饭道山／林业集团（杣五家）→ 祈祷卖药、落地生根 → 「归入恶党最恰当」
 → 【组织】庄园领主衰落、私吞年贡、钩之阵 → 惣村 / 一揆 / 中惣 / 上忍下忍；实力伯仲故「没有以下犯上」
 → 【弱点同源】自治松散、利益本位 → 面对外敌「绝不是团结一致的」
 → 【消亡】信雄两败 → 轻敌 → 天正九年信长亲征、柏原城陷落 → 联盟解体【关键转折】
 → 【分流】乱世→治世：少数被武家招致、多数归农、少数为盗；家康收编、大手三门警卫；岛原之乱为最后舞台；叹请复兴被婉拒
 → 【形象反转】《立川文库》/真田十勇士造出猿飞佐助 → 「俨然如事实一般的英雄」；背后是「大阪人意识」与对江户文化的反抗
 → 【回本色】装束考证：不「一身黑」、不常着锁子甲、刀短且藏 → 「最重要的就是打扮得跟普通人没有区别」
 → 【器物】钩绳 / 打竹 / 石笔 / 药品 / 路程计 / 丝矢 / 移豆 / 听音器 → 忍术＝测量、记录、窃听的实用技术
```

**关键前提**：①「忍者」可作为一类**社会群体**被定义，且其本质可由「不隶属领主」这一政治属性给出；②秘传书、古记录、系图与处刑记载足以判定人物真伪，文学文本则应归入另一层；③大众形象与史实形象的落差本身值得解释。第①条是全书最核心也最可商榷的设定——「不隶属领主」解释了兴起，却难解释转仕信长、家康后的忍者仍被称为忍者，作者在收编部分实际上放宽了自己的定义。【推断】

## 9. 可迁移模型/行动清单

**模型 A：「去神秘化四问」**——遇到任何被传说包裹的群体或职业，依次问：①**第一因**是什么（是地理／技能，还是制度与权力结构）？②**社会出身**是什么（本书：恶党、修验者、林业集团）？③**组织形态**是什么（松散联盟还是统一体？均势如何维持）？④**消亡条件**是什么（是技艺失传，还是需求结构消失）？

**模型 B：「史料分层表」**——把每个名字放进三档：**可确证**（有处刑、公文、可靠记录，如石川五右卫门「实有其人」）／**有异说**（不同古文献互相冲突，如狙击信长者是谁「其真伪已不得而知」）／**文学虚构**（正史与军记均不见，如猿飞佐助）。凡遇「据说」「相传」「笔者推定」「被大多数人接受的」，一律降一档并标注。

**模型 C：「优势—弱点同源」检查**——一个组织的核心优势（自治、均势、不隶属）往往正是它在危机中的弱点（无法统一行动、利益本位、易被各个击破）。评估组织时，把「它为什么成功」与「它为什么失败」用同一组结构特征各写一遍。

| 步骤 | 操作 | 判断标准 | 边界 |
|---|---|---|---|
| 1 破形象 | 列出流行印象，逐条找反证 | 是否有「实际上／其实是」类材料 | 反证本身也可能来自后出文献 |
| 2 找第一因 | 在地理、技术、制度间比较解释力 | 能否解释「条件相似却结果不同」 | 本书以地形相反却同产忍者立论 |
| 3 溯出身 | 查群体的经济来源与身份转化 | 是否有「由 X 变为 Y」的中间环节 | 甲贺说作者自标「被大多数人接受」 |
| 4 画组织 | 找联盟条约、分工、决策方式 | 是统一体还是自主联合体 | 结构松散不等于无组织 |
| 5 定真伪 | 按三档分层并标不确定语气 | 是否保留异说而非择一 | 不替作者补出处 |
| 6 看消亡 | 问「需求」还是「能力」先消失 | 人群是否仍在、只是职能不在 | 收编后「忍者」定义被放宽 |

**行动清单**：① 遇「神秘群体」先问「谁给他们发工资／他们不隶属谁」；② 把「据说／相传／推定」单独列一栏；③ 用「实力伯仲」解释「没有以下犯上」这类反常现象；④ 用「同一结构特征」同时解释兴与亡；⑤ 区分「史实人物」「被重塑的史实人物」（石川五右卫门）与「纯虚构人物」（猿飞佐助）三类，不要合并；⑥ 对「忍术是否有效」保留作者自己的设问，不替秘传书背书。【推断】

## 10. 局限与争议

1. **核心定义与后文张力**：以「不隶属于任何一个领主」为忍者本质，能有力解释兴起，但书中大量篇幅写的正是转仕六角氏、信长、家康、幕府之后的忍者（泷川一益、甲贺组、大手三门警卫）。作者未重新界定「收编后还算不算忍者」，而是用「忍者们的生存能力很强……在太平盛世中，他们依然顽强地生存了下来」带过，定义前后宽严不一。【原文·开篇/消亡/山冈景友；争议为推断】
2. **史料可信度未系统说明**：全书引《万川集海》《伊乱记》《正忍记》《上忍定本奥忍秘帖》《绘本太阁记》《禁贼密诚谈》《立川文库》等，但除「《绘本太阁记》……这种说法却没有任何根据」等零星判断外，未交代各文献的成书年代、作者与可信度等级；对「天正十年成书，延宝四年写本」一类细节也是随文带出。读者难以独立判断何为信史。【推断】
3. **部分推断语气未与叙述分离**：作者多处自标「笔者推定」「关于他的出身有很多谜团，并没有定说」「据说」「被大多数人接受的」，这是可贵的谨慎；但如「一益和信长之间的关系，恐怕是通过铁炮建立起来的」「估计是受了泷川一益的影响」等心理与因果推断，仍与史实叙述并列，未统一标注层级。【原文·分段；推断】
4. **「梦中的忍者」的文学—社会解释可商**：把《立川文库》的英雄塑造归为「大阪人意识」「对江户文化的反抗思想风潮」，并称「《立川文库》中没有一点礼赞德川（家康）的影子」，是有启发性的解释，但素材中未见对出版年代、读者构成与文本传播的进一步举证，属解释性假说。【原文·第三节(3)；推断】
5. **器物部分的效用存疑被自认**：作者自问「『水云』等，名字颇为人所知，但是到底使用上有没有效果呢？」，并说明「水云……并不是在水上行走的工具，而是可以折叠的便携式小船」「因为潜在浅水中很容易被发现，所以这种用具不太实用」；但其他忍器（低声听取金片、听筒、丝矢之术）多以秘传书记载为据直陈其用，效用判准并未一以贯之。【原文·金句/结尾；推断】
6. **叙述中的价值判断**：如「他们认为自己很委屈」类心理描写、「信长就是那种开拓新时代的主君」「他所重视的是拥有特异才能的人」等，属带文学性的评述；另有对「苛政」「锁国」等背景的简略交代，未展开制度分析，读者宜与考据部分分层看。【原文·分段；推断】
7. **阅读局限声明**：本笔记依据自动抽取素材，可读到起源六节、多数人物列传、梦中的忍者三节与装束/忍器部分；「其余 75 个标题」「其余 34 段」未展示，中后段忍器条目、甲贺人物列传后半与注释仅见标题或片段，**待核**。另作者生平、出版年、版本与书目信息均**材料不足**。【阅读局限】

## 11. 思维导图大纲

- 《忍者——生于黑暗的军团》叶宗翰｜约 4.25 万字｜日本中世军事文化史·考据
  - 0 设问：忍者为何神秘？两大圣地为何是伊贺与甲贺
  - 1 第一因（伊贺、甲贺与忍者(1)）
    - 伊贺：「隐秘之国」，离京都八十公里，仅翻山口可入
    - 甲贺：地势开阔、北临琵琶湖、道路四通
    - 技能条件：草药采制 / 火药 / 锻冶 / 表演歌舞；庄园归属复杂
    - 结论：最重要是政治原因——无实力相当的大领主可投靠
    - 定义：「不隶属于任何一个领主的地方武士小集团联盟」
  - 2 两条发生学路径
    - 伊贺＝恶党：镰仓后期—南北朝被镇压的地方武装 → 独特战法、夺年贡储村、村落守护体制 → 楠木正成（父为散所之长）、吉野皇宫警卫 → 转正为武士

    - 惣村：自主管理、自主防卫
    - 伊贺惣国一揆：共同制定文字条约

## 13. 三档压缩版

**100 字版**：叶宗翰《忍者——生于黑暗的军团》是一部为忍者「去神秘化」的日本中世军事文化考据：它把忍者还原为「不隶属于任何一个领主的地方武士小集团联盟」，指出伊贺出自「恶党」、甲贺出自修验道场与林业集团，而两地共通的第一因是「没有一个能让他们投靠的大领主」；再以惣村、一揆、中惣、上忍下忍说明其自治联盟形态，以天正伊贺之乱与乱世终结解释其消亡，并以「梦中的忍者」一章说明猿飞佐助等形象实为《立川文库》等大众文学所造。

**300 字版**：本书要回答：被民间传说与影视塑造成「一身黑、飞檐走壁、善幻术」的忍者，在真实历史里究竟是谁？作者的核心论断是「忍者集团最初的本质，就是不隶属于任何一个领主的地方武士小集团联盟」。论证从排除地理决定论开始：伊贺是「离京都只有八十公里」、除翻山口外无路可通的「隐秘之国」，甲贺却「地势开阔，北临琵琶湖」而道路四通，地形相反却同为两大圣地，故「最重要的一点其实是政治原因：在这两地，没有一个可以与这些地方势力集团实力相当的、能让忍者集团投靠其麾下的大领主」。两条发生学路径随之展开：伊贺忍者「其实是从所谓的『恶党』演变而来的」，经楠木正成、吉野皇宫警卫而「成了名正言顺的武士集团」；甲贺则「被大多数人接受的，乃是甲贺忍者是由修验道场产生的说法」，饭道山的修验者「以祈祷、卖药为生」，成为「最后形成忍者军团的核心人士」。组织上，伊贺建「惣村」自主防卫、以文字条约结成「伊贺惣国一揆」，甲贺有「同名中惣」「甲贺郡中惣」；因「实力都在伯仲之间」，甲贺竟「没有以下犯上的现象出现」。但同一松散结构也是弱点：天正伊贺之乱中「伊贺的忍者们也绝不是团结一致的」。信雄两度贸进攻伊贺被击退，反使忍者轻敌，天正九年信长亲征，「六天内伊贺的大部分区域为信长军所控制」。乱世终结后「只有少数运气很好的忍者……被武家招致麾下，其他多数成为普通农民，少数人则成为盗贼」，江户时代虽被收编为「大手三门」警卫，「岛原之乱，是忍者们大活跃的最后舞台」。全书最见方法自觉的是「梦中的忍者」一章：猿飞佐助「与真田氏有关的正史自不待言，在《真田三代记》中也见不到」，是「在说书人的团扇里被推出来的英雄」；而石川五右卫门则被细分为「可以确定历史上实有其人」但身份是盗贼、后世层层加光。结尾的装束与忍器考证回到本色：「最重要的就是打扮得跟普通人没有区别」，忍术多是测量、记录与窃听的实用技术。

**800 字版**：《忍者——生于黑暗的军团》（叶宗翰，元数据 publisher 标 COAY.COM，全文字数约 42534 字）是一本以「去神秘化」为志趣的日本中世军事文化史读物。它不教忍术，不讲传奇，而是追问一个社会史问题：被民间传说及文学作品包裹上「极其浓重的神秘色彩」的「黑暗武士」，真实身份究竟是什么、从怎样的结构中产生、又为何消失？开篇先把最流行的解释挡回去。作者指出忍者「有很多流派和产生地，最有名的两大圣地是伊贺和甲贺」，而两地自然条件截然相反：伊贺「离京都只有八十公里，自古以来就被称为『隐秘之国』，这个地方除了翻越山口进入之外，再无他路可通」；「与伊贺仅一山之隔」的甲贺「地势开阔，北临琵琶湖，几乎与近畿以东的各国道路全都相通，与伊贺隐秘的地形大异其趣」。两地又都有大量庄园与修验道场，居民中「精于草药采制者很多，擅长使用火药的也不在少数，还有长于锻冶的家族，甚至还有擅长表演和歌舞的团体」。但作者的结论是：「除了上述地理和技能上的原因使得这两处能产生忍者集团外，最重要的一点其实是政治原因：在这两地，没有一个可以与这些地方势力集团实力相当的、能让忍者集团投靠其麾下的大领主。因此，忍者集团产生了。忍者集团最初的本质，就是不隶属于任何一个领主的地方武士小集团联盟。」这句定义是全书枢纽。随后分述两条发生学路径。伊贺一路：「其中的伊贺忍者，其实是从所谓的『恶党』演变而来的」，而「恶党」「日本历史上是指从镰仓幕府后期到南北朝期间一直为统治者所镇压的地方武装势力以及零散的武装农民」，作者还特意说明「今天我们说这个名词的时候，已经没有了褒贬的意义」。被列为「第一代忍者大将」的楠木正成，其父「是散所之长」——散所是权贵、佛寺、神社手下从事交通土木工程杂役而免年贡之处，「云游艺人、赌徒、妓女等游民也会大量流入其中，而集合了这些下层阶级的『长』就是『恶党』首领」；正成助后醍醐天皇、以赤坂城千早城抗镰仓，其死后「伊贺『恶党』更是担任了吉野皇宫的警卫之职」，于是「终于成了名正言顺的武士集团——伊贺忍者，自此登堂入室」。甲贺一路则标为「被大多数人接受的，乃是甲贺忍者是由修验道场产生的说法」：饭道山「山峰标高六百六十四米，是被称为『近江的大峰山』的山岳信仰灵地」，相传开山者为「修验道场的祖师——役行者」（因头上有角又称「役小角」，《日本灵异记》载其「每天乘五色祥云在天空中飞翔」）；修验者「住在山麓娶妻生子，浑然一体，落地生根拥有土地，把修验中获得的知识渗透到农村，也走上了地方武士的道路」，且「多数人以祈祷、卖药为生，在甲贺，这些人被认为是最后形成忍者军团的核心人士」。组织形态是第三层。「钩之阵」一节写南北朝内乱使「庄园领主的统治力逐渐削弱」，地方武士「代庄园收取年贡，并将收来的年贡据为己有」，背后有近江守护六角氏撑腰，遂招致比叡山与朝廷大臣要求足利幕府讨伐、第九代将军义尚亲自出阵；结果是甲贺形成「同名中惣」与「甲贺郡中惣」的「地方小领主联合体」，且「并不是一个全员一致的统一联盟，而是一个各自具有一定自主性的联盟。这样的体制客观上形成了适合忍者成长的土壤」。伊贺则「以族为单位结成团体，各自建构城寨，这样的城寨在伊贺被称为『惣村』。惣村不隶属于任何领主，都是自主管理、自主防卫」，由各集团「共同制定了一个文字条约，缔结成被称为『伊贺惣国一揆』的地方同盟」；集团中「通常被称为『上忍』」者为技术指导者与领袖，「一般进行具体行动的忍者则被称为『下忍』」，后世「上忍」概念还延伸及于「具备了超强隐忍能力的德川幕府的开创者德川家康」。作者特别提示：「战国时代是一个普遍以下犯上的时期，但是在甲贺却没有以下犯上的现象出现」，原因「一是因为他们的实力都在伯仲之间，没有绝对可以凌驾于他人之上者」。但同一结构也埋下败因——「但是，在与织田信长大战的天正伊贺之乱中，伊贺的忍者们也绝不是团结一致的」「其实只要自己的利益能够得到保证，上面的人是谁他们是不怎么在意的」。消亡部分以织田父子的三次冲突为轴：天正六年（1578）信雄修筑丸山城引发危机，伊贺忍者袭城迫其撤退；次年九月信雄「率领八千部队兵分三路，未经信长许可就贸然进攻伊贺，结果再次被伊贺的忍者军团击退」，反使忍者「开始认为『信长并不像人们说的那样强大』，所以对织田信长掉以轻心」；「天正九年九月，一代霸主织田信长终于亲自率领大军，杀向总人口只有九万的伊贺」，「六天内伊贺的大部分区域为信长军所控制，只有柏原城寨坚持抗战」，据《伊乱记》「直到十二月二十八日才终于被攻陷」。人物列传把这段历史落到具体人：城户弥左卫门等三人于敢国神宫以铁炮狙击信长「都没有打中」，弥左卫门被追上后「自行将刀刺入喉头」；杉谷善住坊于千草山卡狙击失败，被「用锯花七天的时间锯死」「据说他一直到第六天才死去」；山田八右卫门在庆典日白天拔走友人佩刀，谜底是同装扮者诱敌、本人藏于拜殿、趁对方摇鳄口铃时从背后取刀，「武士这才注意到，自己手上紧紧握住的只有刀鞘而已」；「会飞的加藤」段藏的「吞牛之术是使用纱幕实行的幻术，鲜花之术则不过是偷梁换柱罢了」；对石川五右卫门，作者据文禄三年（1594）鸭川三条桥南河滩的处刑记载判定「可以确定历史上实有其人」，却立刻补充「在这里我们看到的石川五右卫门并不是一名忍者，而是盗贼」，并说明「江户时代的盗贼往往在歌舞伎等庶民的愿望中被塑造成英雄」。甲贺人物列传则写「转仕」：泷川一益因「私通信长」被六角氏驱逐、后成「信长四天王之一」，其家乡甲贺油日村「早在天文十五年（1546）就开始了火药的制造」；伴太郎左卫门随信长死于本能寺；伏见笼城战中「甲贺武士十人中的五人，忍者百人中约七十人战死」；此后甲贺组被授予江户城本丸「大手三门」警卫、迁居青山；宽永十四年（1637）「融合了无法忍受苛政的农民起义和基督教的宗教战争的双重性质」的岛原之乱被作者断为「忍者们大活跃的最后舞台」；而大原数马等后人向幕府「叹请复兴忍术」、献上《万川集海》十册与《军要秘记》一册，只得到「希望能稍等一段时间」与「银钱五枚」。作者的总结是：「在信长、秀吉、家康将世界由乱世向治世推进的过程中，只有少数运气很好的忍者由于自己的技艺而被武家招致麾下，其他多数成为普通农民，少数人则成为盗贼。」全书最有方法自觉的是第三节「忍者列传之完结：梦中的忍者」：猿飞佐助「与真田氏有关的正史自不待言，在《真田三代记》中也见不到」「可以说他是在说书人的团扇里被推出来的英雄，随着说书人的渲染逐渐被夸大，然后又变成了俨然如事实一般的英雄」，其形象由《立川文库》第五编《真田幸村》到第四十编《猿飞佐助》逐步放大；「真田十勇士」「几乎都是倾慕真田幸村的人们创造出来的人物」，背后是「大阪人意识」「没有一点礼赞德川（家康）的影子」的「对江户文化的反抗思想风潮」；但作者并不否定虚构——「在这些作品中，时代的形势和大众的愿望复杂交织，使得忍者的形象大为改变。这种虚构的形象，应该是可以原谅的吧」。最后以器物考证收回本色：「要在别人不知不觉的情况下进行谍报活动，最重要的就是打扮得跟普通人没有区别」，故「一身黑」不实（「在黑暗里一身黑色打扮反而更加醒目」，应用茶色、烂柿子色、紫蓝色，雪地用白，且有正反两穿的「变衣」）；「忍者是把谍报活动作为自己的主要本领，而不是重要的战斗力量」，故除大规模打斗外不着锁子甲、刀为「五十厘米以内的短尺寸的直刀」且常藏于手杖；「忍者六具」为草笠、三尺手巾、钩绳、打竹、石笔、药品。结尾的忍器条目——路程计（又称「飞脚记」，「以现代的自动上弦钟表发明的原理为基础」，明治时期曾在钟表店出售）、丝矢之术（箭绑标线测壕宽、系秤砣测深）、移豆之术（左右衣袂置豆记录房数）、低声听取金片（印子金薄板以真丝挂耳旁共鸣窃听）、听筒（真鍮伸缩筒，兼作扩音器与吹药粉筒）——把「忍术」还原为测量、记录与窃听技术。读本书须守四条边界：其一，以「不隶属领主」定义忍者，与后半大量转仕、收编的叙事存在宽严不一，作者未重新界定；其二，所引《万川集海》《伊乱记》《信长公记》《正忍记》《立川文库》等未系统交代成书年代与可信度等级，「据说」「相传」「笔者推定」「被大多数人接受的」等不确定语气也未与史实叙述统一分层；其三，作者自己设问「『水云』等，名字颇为人所知，但是到底使用上有没有效果呢？」并指出水云「并不是在水上行走的工具，而是可以折叠的便携式小船」、浅水潜行「不太实用」，但其他忍器多直陈其用，效用判准未一以贯之；其四，素材中「其余 75 个标题」「其余 34 段」未展示，中后段忍器与甲贺列传后半仅见标题，作者生平、出版年、版本与完整书目均材料不足，宜把它读作「一部有明确考据意识、但仍带文学性评述的通俗社会史」，而非可逐条征引的学术定本。
