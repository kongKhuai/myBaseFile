## 1. 一句话主旨

本书要回答：**《周易》究竟是一本什么性质的书、由哪些层次构成、又该怎样学才既能不失其历史面目、又能用来「解决我们的重大困惑」？** 核心答案：必须先把「经」与「传」分开——「《易经》（狭义）是一部占筮书，以占筮成分为主；《易传》是一部哲学书，以哲学成分为主」，汉代经传合一才使性质复杂化；由此逐层全解「文化地位—时代作者—名义—性质—卦爻象（符号）—卦爻辞（文字）—十翼—太极阴阳五行—占卜—入静观象法」，并把「周易」的深层含义定为「周环或周期的变化」。

**区分性**：这不是《周易》译注（只逐卦注经文），不是义理派或象数派的专门著作（只取一家），也不是占卜操作手册，而是**以「经／传分观」为总方法、把两千年的性质之争先作学术裁决、再铺开为一套从头到尾的「全解」框架**的通论；它最鲜明的动作是用一句对称判断收束性质之争——「《易经》是带有哲学色彩的占卜书，《易传》是带有占卜色彩的哲学书」。同主题书多重「某一卦怎么解」，本书重「这部书整体是什么、由什么构成、怎么学」。【推断】

## 2. 核心问题链

1. **《周易》是什么、由什么构成？**——目录立框架：文化地位、构成、时代与作者、「周易」的含义、性质、卦爻象（符号系统）、卦爻辞（文字系统）、《易传》内容、解《经》方法、太极与太极图、阴阳与五行、天干地支、河图洛书、占卜、怎样对待占卜、学《易》的方法。（目录）
2. **它成于何时、出于谁手？**——重卦有伏羲、神农、夏禹、文王诸说；《周礼》「其经卦皆八，其别卦皆六十四」说明至迟夏代已用六十四卦；出土「奇字」被指为「数字卦」；卦爻辞「非出于一人之手，是卜筮者长期探索积累的结果」；《易传》旧题孔子作，欧阳修《易童子问》始疑，今人多数认为「十翼」均非孔子所作。（时代与作者）
3. **「周」「易」二字怎么讲？**——「周」有四解（周代／周地／周普／周环周期），「易」有七解（变易三义、日月、生生不息、逆数、蜥蜴、蚕与太阳等）；作者断「『易』字的本义就是『变易』」，「周易」表层为「周代或周地的占筮」、深层为「周环或周期的变化」。（「周易」的含义）
4. **《周易》是卜筮书、哲学书、历史书、科学书还是百科全书？**——历数朱熹、郭沫若、高亨、李镜池、刘大钧（卜筮）；庄子「《易》以道阴阳」、李景春、黄寿祺（哲学）；章太炎、胡朴安、李平心、黎子耀（历史）；冯友兰「宇宙代数学」与科学易派（科学）；以及智能逻辑、最古辞书、敌情报告等说。（《周易》的性质）
5. **这些争论错在哪？**——「以上种种观点，虽各执一端，各据其理，但都犯了一个错误，即将《周易》『经』和『传』不加区分地混为一谈」；「对此只有采用历史的态度和分析的方法，才能把握……性质」。（转折句）
6. **卦爻符号是什么？**——「爻是《周易》最基本的符号，卦的最小构成单位」，分阳爻阴爻；「卦爻符号不仅是《易经》的符号系统，而且也是中华文化的『基因』」；爻的本质特征在「效」和「动」，卦与爻是「体」与「用」。（卦爻象／爻与卦）
7. **文字系统由什么组成，与符号系统什么关系？**——卦名 64、卦辞 64、爻辞 386（含乾坤「用爻」）；作者主张《易经》「主要有两大要素，一是『象』，一是『辞』」，数归象、义归辞、占与变属用途层面；对「象—辞」关系取中道：「最初的结合只是出于占筮的需要，但经过长期的整理、修正、加工，可看出编纂者有将两者逻辑化、条件化的企图」，完全否定或神化「都是不可取的」。（卦爻辞／关系）
8. **《易传》做了什么？**——「《易传》的最大贡献就是将《易经》从巫术转变为哲学，从迷信转变为理性」，故可称「穿着卜筮外衣的哲学」；十翼七种，彖传释卦义（义理德行／爻位／形象三法，重「时」「位」）、象传分大象小象、文言传仅乾坤、系辞传为通论并「将《易》由一本占筮书变成了哲学书」。（《易传》的内容）
9. **阴阳五行、太极图、河图洛书怎么定位？**——作者明说五行「作为一种模型被中医广泛运用时，已不含有『元素』『要素』的名词意义」，「五行就是『气』的演化模型，就是时间与空间合一的理论模型」。（金句）
10. **占卜该怎么对待、学《易》怎么入手？**——专设「怎样对待占卜」「学《易》的方法——入静观象法」三节；结尾把观象与「潜意识」相联：「只有心静才能进入潜意识状态……才能找到符合你处境的卦象」，并以「信心是心灵最有力的触手，也是开发潜意识的必要前提」收束全书。（结尾）

**逻辑关系**：从**框架**（目录）→ **考据**（时代作者、名义）→ **裁决**（性质之争＝经传不分）→ **结构**（符号系统＋文字系统＋二者关系）→ **转化**（《易传》把巫术变哲学）→ **模型**（太极、阴阳五行、干支、河洛）→ **应用与修习**（占卜、入静观象）。前七步是「历史的态度和分析的方法」，最后一步转入体验与潜能话语，两部分标准不同，是全书最需分层处。【推断】

## 4. 中心思想（命题式）

1. **《周易》的性质之争源于「经」「传」不分，须以历史的态度分层裁定**——主张：「《易经》（狭义）是一部占筮书，以占筮成分为主；《易传》是一部哲学书，以哲学成分为主」；理由：卜筮说（朱熹「易本卜筮之书」、郭沫若、高亨、李镜池、刘大钧）、哲学说（庄子「《易》以道阴阳」、李景春、黄寿祺）、历史说（章太炎、胡朴安、李平心、黎子耀）、科学说（冯友兰「宇宙代数学」、科学易派）、百科全书说等「各执一端，各据其理」，却都「将《周易》『经』和『传』不加区分地混为一谈」；汉代经传合一「尊为《易经》（广义）」才使性质复杂化。限定：作者并未把二者截然割裂，而是给出交叉表述——「《易经》是带有哲学色彩的占卜书，《易传》是带有占卜色彩的哲学书」，即分层是**成分与主次之分**，不是有无之分。【原文·《周易》的性质／转折句】

2. **「周易」的深层义是「周环／周期的变化」，「易」的本义是变易**——主张：「我认为『周易』表层的含义是『周代或周地的占筮』，深层的含义是『周环或周期的变化』」；理由：「周」四解中作者取「周环、周旋、周期」，并以卦序为证——「六十四卦从乾、坤开始到既济、未济，是一个运动周期（『既济』为本次周期的完结，『未济』为下次周期的开始）」，又引「复」卦「反复其道，七日来复」；「易」七解中作者取蜥蜴善变引申，「郑玄的三义说、毛奇龄的五义说……均是对『变易』的引申、发挥」。限定：这是**作者个人的取舍**（「我认为」），他同时完整罗列了四解与七解，并承认「循环、周期是《周易》揭示的宇宙生命的最根本规律」属义理层面的判断，非考据结论。【原文·「周易」的含义／金句；限定为推断】

3. **卦爻符号是中华文化的「基因」，《易经》的构成要素只有「象」与「辞」两类**——主张：「卦爻符号不仅是《易经》的符号系统，而且也是中华文化的『基因』」；「我认为《易经》主要有两大要素，一是『象』，一是『辞』」；理由：文化基因须「体现为一定形式的物质形态」，而卦爻「是中华民族最早的、有形的符号，同时它以及对它的解读体现了中华民族传统的思维方式和深层的心理结构」，兼具形而上与形而下；此外「数」可归入「象」（「九四」即第四爻阳爻，「六三」即第三爻阴爻），「义」可归入「辞」，「占」「变」属用途层面「与『象』『辞』不在同一个层面上」。限定：作者用「基因」「DNA」「染色体」作**类比**，属现代生物学概念的借用，并非实证的遗传学论断；且他明说「从某种意义上说」，保留了修辞空间。【原文·卦爻象／卦爻象与卦爻辞；限定为推断】

4. **《易传》完成了「巫术→哲学、迷信→理性」的转化，其方法是「穿着卜筮外衣」的义理化**——主张：「《易传》的最大贡献就是将《易经》从巫术转变为哲学，从迷信转变为理性」，「可以将《易传》称为穿着卜筮外衣的哲学」；理由：作为解经之作「不能破坏卦爻符号、卦爻辞的神圣，不能不从象数、义理两方面来阐发」，作为哲学著作「又必须突破其巫术的迷信因素，并建立起自己的思想体系」；彖传以义理德行、爻位、形象三法释卦义并重「时」「位」，象传以「天行健，君子以自强不息」式句子把卦象转为德目，系辞传为通论「将《易》由一本占筮书变成了哲学书」。限定：作者同时承认《易经》本身「虽是一部占筮书……但并不是一般的迷信书」，因它「增加了人为因素，增加了趋吉避凶的价值选择因素」，具有「安身立命、稳定情绪、安慰心理」的人文色彩——即**转化并非从零开始**，经文已含理性与人文萌芽。【原文·《易传》的内容(1)／系辞传／卦爻象与卦爻辞的意义】

5. **对象—辞关系与占卜都须取「中道」：既不全盘神化，也不全盘否定，并落到「心静观象」的修习**——主张：「完全否定两者的关系或完全肯定以至于神化两者关系这两种倾向都是不可取的」；「卦象和卦爻辞之间最初的结合只是出于占筮的需要，但经过长期的整理、修正、加工，可看出编纂者有将两者逻辑化、条件化的企图」；占卜被定义为「预测这种变化的趋势……给预测者提供一种趋吉避凶的方法」。限定：结尾的「入静观象法」把观象与「潜意识」「潜能」「宇宙意识」「心灵感应等 ESP 能力」相联，并以墨菲博士、自我暗示、「不断地想着你的目标，这样的话，你的目标终究会实现的」作结——这已进入**体验与励志话语**，与前文「历史的态度和分析的方法」不是同一论证标准，读者宜分层看待，不宜与考据结论等量齐观。【原文·卦爻象与卦爻辞的关系／金句／结尾；限定为推断】

## 5. 内容梗概（非虚构·理论通论）

- **问题**：《周易》到底是什么性质的书？历代把它分别判为卜筮、哲学、历史、科学、百科全书，争议未决；同时读者还想知道它由什么构成、如何读、如何用于人生。
- **方法**：**「分层＋罗列＋折中」三步**。分层即经／传分观、符号／文字分观、象／辞分观、考据／义理／修习分观；罗列即把每一问题的诸家之说与代表文献一一点名（重卦四说、「周」四解、「易」七解、性质六类、卦爻辞断代诸家、易传作者疑案）；折中即在两偏之间给出「我认为」的判断（本义变易、两大要素、象辞关系「有的卦相关性强一些，有的卦相对弱一些」、当位「并非判断吉凶利弊的绝对标准」）。【原文；方法命名为推断】
- **证据**：①**文献**——《史记·周本纪》《魏志·高贵乡公纪》《淮南子·要略训》《周礼·春官·宗伯》《易纬·乾凿度》《说文解字》《周易参同契》《左传》《尚书·洪范》《墨子》、郑玄《易赞》《易论》、王弼韩康伯注、孔颖达《周易正义》、朱熹《周易本义》、欧阳修《易童子问》、崔述、《六艺论》；②**出土与近人考据**——丰镐、周原遗址卜骨卜甲「奇字」、张政●等「数字卦」说、张亚初与刘雨的材料收集、顾颉刚《周易卦爻辞中的故事》以「康侯」即卫康叔断非文王作、马王堆帛书《易传》无「大衍之数」段；③**今人诸说**——郭沫若、顾颉刚、李镜池、陈梦家、高亨、李景春、黄寿祺、章太炎、胡朴安、冯友兰、刘大钧、黎子耀等；④**外域比附及其澄清**——莱布尼茨二进制（作者指出「事实上是莱布尼茨看出『伏羲六十四卦方位图、次序图』与他早就发现的二进制理论吻合」）、玻尔互补原理、李约瑟、卡普拉；⑤**文本内部**——卦序乾坤→既济未济、复卦「七日来复」、爻名九六、卦爻辞中「高宗伐鬼方」「帝乙归妹」「康侯用锡马蓄庶」等史事。【原文】
- **结论**：经传分观（《易经》占筮为主、《易传》哲学为主）→「易」本义变易、「周易」深层为周期变化 →《易经》要素为象与辞 →《易传》完成哲理化 → 五行等为「气」的演化模型 → 占卜是预测变化趋势与趋吉避凶 → 学《易》须「入静观象」。并以「如果说《易经》是中华文化的源头……那么《易传》就是中华文化的活水」收束文化定位。【原文·金句/结尾】
- **应用边界**：一是**「全解」为框架性通论**，逐卦逐爻的详解在素材中未见（「其余 124 个标题」「其余 98 段」未展示），不能据此认为本书已完成六十四卦逐卦解读；二是**引文与人名有抽取残缺**（如「张政●」「揲●」「变?」「『夬』『 、萃』」），本笔记不补全；三是**考据层与修习层标准不同**（见命题 5）；四是作者以「我认为」明示的个人判断，须与「传统上主要有……」「今人多数认为」等转述分层。【推断】

## 7. 论证链或叙事线

```
【设问】《周易》是本什么性质的书？「古往今来，仁者智者，争议未决」
 → 【罗列】卜筮说 / 哲学说 / 历史说 / 科学说 / 百科全书说 / 智能逻辑·最古辞书·敌情报告等
 → 【诊断】诸说「都犯了一个错误」＝经传不分；经传是不同时代产物、性质完全不同
 → 【裁决】《易经》(狭义)＝占筮书为主；《易传》＝哲学书为主；汉代合一使性质复杂化
 → 【交叉限定】《易经》是带哲学色彩的占卜书，《易传》是带占卜色彩的哲学书【关键转折】
 → 【考据支撑】重卦诸说 / 数字卦 / 卦爻辞非一人之手、卜筮者长期积累 / 十翼非孔子作
 → 【名义】「易」本义变易 → 诸义皆引申；「周易」深层＝周环周期的变化（卦序、复卦为证）
 → 【结构一·象】爻→卦→卦爻符号＝中华文化基因；爻主「效」「动」，卦爻为体用
 → 【结构二·辞】卦名64 / 卦辞64 / 爻辞386；九六为可变之数
 → 【合】数归象、义归辞、占变属用途 → 两大要素＝象与辞；象辞关系取中道
 → 【转化】《易传》十翼：彖(义理/爻位/形象·时位)、象(大象小象)、文言(乾坤)、系辞(通论)
 → 结论：从巫术到哲学、从迷信到理性；经文已含生活经验、忧患意识、理性思维
 → 【模型】太极两仪四象八卦 / 阴阳五行(气之演化模型) / 干支 / 河洛
 → 【应用】占卜＝预测变化趋势 + 趋吉避凶；大衍之数、遇观之否
 → 【修习】入静观象法：心静 → 潜意识 → 卦象 → 信心与潜能【标准转换：由考据转体验】
```

**关键前提**：①「经」与「传」在成书时代与性质上可以清晰二分，且这一二分足以解释历代性质之争；②符号系统可被当作「文化基因」并以形而上／形而下双重条件论证；③《易传》的义理化是「转化」而非「误读」；④「心静—潜意识—卦象」之间存在可操作的关联。前三条有文献与文本内证支撑，第④条引入的是另一套（心理学／励志）话语，本书未给出与前文同等级的论证。【推断】

## 9. 可迁移模型/行动清单

**模型 A：「分层裁决四步」**——遇到任何「众说纷纭、争议未决」的对象：①**罗列**诸说并各给代表人物与文献；②**找共同错误**（本书＝经传不分）；③**按层次切开**（时代／成分／用途／文体）；④**给交叉限定**（不是「非此即彼」，而是「以什么为主、带什么色彩」）。

**模型 B：「要素归并法」**——面对一个被列出四要素、五要素的体系，先问「哪些是构成，哪些是用途」：本书把「数」归入「象」、「义」归入「辞」，「占」「变」判为用途层面，于是四要素收敛为两大要素。判准是「是否在同一层面上」。

**模型 C：「两偏之间」检查表**——凡遇「必然对应／全无关系」「绝对标准／毫无标准」之争，先写下两极，再找作者给出的中间项（「编纂者有将两者逻辑化、条件化的企图」「有的卦相关性强一些，有的卦相对弱一些」「当位、不当位并非判断吉凶利弊的绝对标准」）。

## 10. 局限与争议

1. **前后论证标准不一**：前半以「历史的态度和分析的方法」裁决性质之争，结尾「入静观象法」却引入「潜意识一经开启，将和宇宙意识产生共鸣，宇宙信息就会以图像方式浮现出来，心灵感应等 ESP 能力也将一一出现」「不断地想着你的目标……你的目标终究会实现的」等表述，并引「潜意识大师墨菲博士」。二者未作方法上的衔接或层级声明，是全书最需读者自行分层之处。【原文·结尾；争议为推断】

**300 字版**：本书要回答《周易》「是本什么性质的书」这一「古往今来，仁者智者，争议未决」的问题，并给出一套从头到尾的「全解」框架。先做考据：重卦有伏羲、神农、夏禹、文王诸说，《周礼》「其经卦皆八，其别卦皆六十四」说明至迟夏代已用六十四卦，出土「奇字」被释为数字卦；卦爻辞「非出于一人之手，是卜筮者长期探索积累的结果」；《易传》旧题孔子作，欧阳修《易童子问》始疑，今人多数认为十翼非孔子所作。再做名义裁定：「易」本义为变易（蜥蜴善变），「周易」表层是「周代或周地的占筮」、深层是「周环或周期的变化」，内证是乾坤至既济未济为一周期、复卦「七日来复」。全书枢纽是性质裁决：罗列卜筮说（朱熹、郭沫若、高亨、李镜池、刘大钧）、哲学说（庄子「易以道阴阳」、李景春、黄寿祺）、历史说（章太炎、胡朴安、李平心、黎子耀）、科学说（冯友兰「宇宙代数学」、科学易派）与百科全书说后，指出「都犯了一个错误，即将《周易》『经』和『传』不加区分地混为一谈」，故须「采用历史的态度和分析的方法」。结构上，《易经》要素被收敛为「象」与「辞」两类——数归象、义归辞、占与变属用途层面；对象辞关系取中道，「完全否定」与「神化」两偏皆不可取。《易传》十翼（彖、象、文言、系辞等）完成「从巫术转变为哲学，从迷信转变为理性」，可称「穿着卜筮外衣的哲学」。后续太极、阴阳五行（「气」的演化模型、时空合一模型）、干支、河洛与占卜属模型与应用层，结尾「入静观象法」把观象与潜意识、潜能相联，须与前文考据分层阅读。

年马王堆帛书《易传》本没有此段记载」），以「太极—两仪—四象—八卦」立宇宙序列，「将《易》由一本占筮书变成了哲学书，由迷信书变成了理性书」；作者以「如果说《易经》是中华文化的源头……那么《易传》就是中华文化的活水」作文化定位。后续模型与应用层（素材多仅见目录与金句）把五行重新定位为「『气』的演化模型，就是时间与空间合一的理论模型」，明说「已不含有『元素』、『要素』的名词意义」，并论太极图与巴比伦双蛇交尾、古希腊古印度等地「●」纹饰之别；占卜被定义为「预测这种变化的趋势……给预测者提供一种趋吉避凶的方法」，举例「观卦就是本卦或遇卦，否卦就是之卦或变卦……『遇观之否』」。全书结尾转入「入静观象法」：先论潜意识「能量巨大；最喜欢带感情色彩的信息；不识真假，直来直去；易受图像刺激；记忆差，需强烈刺激或重复刺激；放松时，最容易进入潜意识」，引墨菲博士「不断地用充满希望与期待的话，来与潜意识交谈」，再说「我们在看《周易》卦象时，只有进入潜意识态，才能发现她的秘密」「只有心静才能进入潜意识状态……才能找到符合你处境的卦象」，最后以「信心是心灵最有力的触手，也是开发潜意识的必要前提」收束。读本书须守四条边界：其一，前半以「历史的态度和分析的方法」裁决，结尾却进入「潜意识一经开启，将和宇宙意识产生共鸣，宇宙信息就会以图像方式浮现出来，心灵感应等
