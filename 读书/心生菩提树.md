## 1. 一句话主旨

本书要回答：**当人把困境归因于命运、环境、他人或外物时，怎样借一则则禅门对话把注意力一次次拨回「自己的心」，从而在主宰自我、宽容待人、安顿内心上获得可复述的处世方法？** 核心答案：外在没有可以主宰吉凶的东西，也没有可求的奇迹；「要想改变世界，必须先改变自己」，一切解法都落在「要改变的只是自己的心」。

**区分性**：这不是佛学理论书（无系统义理与经典注疏），不是禅宗公案汇编（不标出处、不考传承、不设「参究」提示），也不是单一高僧传记，而是**以数十个格言式标题为纲、每篇一则白话禅门寓言、结尾一段直接点题的修养故事集**——它的组织原则是「同一命题的多故事变奏」，而非论证推进。同为「以今释古」，《庄子解读》依附一部经典逐句讲解，本书则**不依附任何单一经典**，把佛门人物、印度婆罗门、日本武士、中国养鸡场主人等一并纳入同一套「向内转」的框架。【推断】

## 2. 核心问题链

1. **人该把目标定在哪里？**——「做事要选定目标，但如何选择目标，选择怎样的目标也是关键」：盯会移动的水牛则秧成弧线，盯不动的大树则秧直。（找到适合自己的人生轨迹）
2. **意念太重、求全求快会怎样？**——小和尚想捞尽鱼放生，连碎三网；高僧说「底线越低越好……循序渐进，自然会挑得更多、挑得更稳」。（心生的意念不要过重）
3. **「我」有没有价值、由谁定价？**——「米还是那斤米」，在一斤米的不同估价里，「你究竟有多大出息，取决于你到底怎样看待自己」；卖石头的故事里，同一块石头在集市、米铺、珠宝店被认作压纸石、化石、无价宝玉。（自己就是一把标尺／一切都在自己的手中）
4. **命运、吉凶、奇迹能不能外求？**——算命说「一辈子不会有发迹之日」；施主「扮吉相」被追问牛黄、毗勒果皆「不能自救」；求奇迹者被告知「除了你自己以外，世界上根本没有其他的什么可以称为『奇迹』」。（一切都在自己的手中／生命由自己主宰／心的力量是无穷的）
5. **信心为什么能产生看似不可能的结果？**——信徒听船夫说河「差不多到膝盖」便从水面走过，释迦牟尼解释「他对我所说的办法有绝对的信心」；又老又病的老妇「凭着无比坚定的意志力，她两个星期就得道了」。（心的力量是无穷的／坚定清净的信心）
6. **逆境、创伤、劳苦是障碍还是条件？**——一年无风雨烈日的麦子「长得又高又好，但是……麦穗里什么都结不出来」；又干又硬的路留不下脚印，泥泞的路才留得下；石阶质问佛像，答「谁叫你当初受不了苦，没敲几下就哇哇叫呢！」。（每一种创伤，都是一种成熟／改变环境靠聪明，改变心境靠智慧／结尾）
7. **面对冒犯与过错，该惩罚还是包容？**——慧远法师被撞碎眼镜而不生气；盘珪禅师两度不罚行窃学生，「因为他需要我的教诲」；一匙盐放入一杯水则咸、放入一盆水则「感觉不到咸味」。（宽容是对生命的洞见／宽容是最好的教育法则／心存一颗包容的心）
8. **「我」究竟是烦恼的根源还是解法？**——「唯一真正需要改变的，其实只是自己的心态」；「你还带着你的所有麻烦的根源——也就是你自己」；「并不是你所遇到的环境使你受到了挫折，而是由于你对各种情况的想象」。（要改变的只是自己的心／心无外物才是超然的境界）

**逻辑关系**：从「目标怎么定」的**方法起点** → 到「自我价值由谁定」「能否外求」的**主体性确立** → 到「信心如何生效」的**动力说明** → 到「逆境何以必要」的**条件反转** → 到「如何待人」的**关系展开** → 收束于「万法归心」的**总命题**。全书不是线性论证，而是**同心圆式反复回环**：每一篇都单独成立，又都回到同一个圆心。【推断】

## 4. 中心思想（命题式）

1. **价值不由外界估价决定，而由自我认定决定**——主张：「你究竟有多大出息，取决于你到底怎样看待自己」；理由：同一斤米在炊妇、农民、卖粽子人、制饼者、制酒商眼中值两三碗饭、一元、三元、五元、四十元，「米还是那斤米」；同一块石头被依次认作压纸石、化石、内含无价宝玉的「和氏璧」。限定：本书把「自我认定」当作价值实现的**起点**而非充分条件——卖石头故事里小和尚最终「静心按照老和尚的旨意做事，最终成了有名的禅师」，即仍须落到持续行动，不是仅凭自我感觉良好。【原文·自己就是一把标尺／一切都在自己的手中】

2. **外求无效，主体性是唯一的着力点**——主张：「世上根本没有一个外在的可以主宰吉凶的东西」「求人不如求己」；理由：施主以牛黄、贝壳、毗勒果「扮吉相」，修行僧逐一追问其来源，指出果实「自身却无法守住这棵树」、枝叶「被做成柴薪燃烧而不能自救」，故「怎么又能保护得了人类呢」；求奇迹者被点破「除了你自己以外，世界上根本没有其他的什么可以称为『奇迹』」。限定：本书并未否定外力——「外在的帮助固然重要，但只有自己才能真正地主宰自己」，明确给外在帮助留了位置，只是不接受由它主宰。【原文·生命由自己主宰／心的力量是无穷的】

3. **信心与专注的强度决定成事的上限，但须以「循序渐进」为约束**——主张：「渴求强烈才能心无旁骛」「志乃心生，更需全心全意」；理由：僧人把年轻人按入水中，问「除了想上岸之外，还考虑别的事吗」，答「我只想得到空气」；默造城垣与默造毫毛「都是用全部的心去造」，故「你的心是能大能小」；信徒因「绝对的信心」而能从恒河水面走过。限定：同一批篇章又给出反向约束——「心生的意念不要过重」，小和尚「想把这些鱼都捞起来」反而连碎三网，高僧劝「底线越低越好……循序渐进」。即**强度针对方向，节制针对速度**。【原文·渴求强烈才能心无旁骛／志乃心生／心生的意念不要过重】

4. **逆境是成就的必要条件，顺境反而是隐性损耗**——主张：「每一种创伤，都是一种成熟」；理由：婆罗门求来一年「没有狂风暴雨，没有电闪雷鸣」，麦子「长得又高又好，但是……麦穗里什么都结不出来」；玄真大师在又干又硬的路「找不到自己的脚印」，雨后泥泞才留得下；石阶不服佛像受礼赞，佛像答「谁叫你当初受不了苦，没敲几下就哇哇叫呢！」。限定：本书把「苦」定位为**锤炼**而非目的，且承认安逸的诱惑真实存在——「如果整天活在安逸中，看起来是很享受，其实无异于是活在地狱中」；它不主张自寻苦吃，而主张在已来的苦中不退缩。【原文·每一种创伤／改变环境靠聪明／结尾】

5. **宽容不是退让，而是更有效的影响方式与更大的心量**——主张：「宽容是对生命的洞见」「宽容是最好的教育法则」；理由：慧远法师被撞碎眼镜不生气，理由是「生气既不能使眼镜复原，又不能让脸上的淤青消失」，且「生气只会扩大事端」，多年后对方寄钱谢恩；盘珪禅师两度不罚行窃学生，「因为他需要我的教诲」，学生「感动得热泪盈眶……从此以后再也不偷别人的东西了」；一匙盐在一杯水中咸、在一盆水中「感觉不到咸味」，喻心量扩大则烦恼变淡。限定：宽容有明确边界——养鸡场主人以「少数几个沙弥」代表全体被反问「也同样太不公平了吧」，即本书反对以偏概全，也并未主张对是非不作判断（盘珪明说「你们都能够明辨是非，这是我感到欣慰的」）。【原文·宽容是对生命的洞见／宽容是最好的教育法则／心存一颗包容的心／心怀一颗公正的心】

## 5. 内容梗概（非虚构·实用修养）

- **问题**：普通人在立志、受挫、被冒犯、被评价、盼好运时，习惯把原因放在外部——命数、吉相、奇迹、环境、他人、运气。本书要处理的正是这种「向外求」的惯性。
- **方法**：**「故事—反转—点题」三步单元**。先给一个日常或佛门场景（插秧、捞鱼、卖石头、洗澡、挑水、撞翻供果），再由禅师/老和尚用一句反问制造认知反转（「你能找到自己的脚印吗？」「你盯住的是不是会动的东西？」「牛黄是从哪里来的？」），末尾以一段议论把反转翻成可复述的处世命题。全书不设概念定义、不列步骤、不作体系推演，靠**同一结构的高频重复**让读者自行归纳。【原文·分段；方法命名为推断】
- **证据**：全为叙事性例证，可归四类——①**价值重估**：一斤米、卖石头、自己就是一把标尺；②**外求破产**：算命、扮吉相、求奇迹、恒河涉水；③**苦之必要**：大梵天与麦子、破瓦鞋与泥路、佛像与石阶、挑担渐轻；④**关系与心量**：慧远不生气、盘珪不罚、一匙盐、清心禅师、养鸡场主人、滴水和尚、禅海凿隧道。人物多为「禅师／老和尚／小和尚／弟子」及佛陀、释迦牟尼、大梵天、婆罗门，偶及「明朝」「普陀山」「江户」「大德寺」等场景名。【原文】
- **结论**：「要想改变世界，必须先改变自己」「要改变的只是自己的心」「心无外物才是超然的境界」；操作上可归结为「选固定目标—降低起步底线—用全部的心—在苦中不退—扩大心量—不外求」。
- **应用边界**：一是**例证即全部论据**，故事多为寓言化、无出处、无可核验的对话，其说服力来自「情理上像真的」而非事实或逻辑；二是**命题之间未排序、未处理冲突**（「意念不要过重」与「渴求强烈」如何协调，须读者自行补足）；三是**适用范围偏个人心境与人际**，对制度性、结构性的困境不作讨论；四是后半部分多数篇目仅见标题，完整结论以可读到的篇章为准。【推断】

## 7. 论证链或叙事线

```
【起点】人把困境归于外部：命数 / 吉相 / 奇迹 / 环境 / 他人评价 / 运气
 → 【破外求】算命「一辈子不会有发迹之日」→ 扮吉相者被追问牛黄、毗勒果「不能自救」→ 求奇迹者被点破「除了你自己以外……没有奇迹」
 → 【立主体】「命运其实就像这粒葡萄一样，就在你自己的手中啊！」／「只有自己才能真正地主宰自己」
 → 【定价值】一斤米五种估价「米还是那斤米」→ 卖石头三易其价而人不自知 → 「你究竟有多大出息，取决于你到底怎样看待自己」
 → 【给方法】目标要固定（大树非水牛）＋ 起步要低（底线越低越好）＋ 用心要全（能大能小）＋ 渴求要强（只想得到空气）
 → 【反转条件】顺境麦穗空瘪 / 干硬路无脚印 / 石阶受不了敲 → 苦是成就的必要条件
 → 【扩到人际】不生气（眼镜不复原）／不逐偷窃者（他需要我的教诲）／一匙盐与一盆水／不以偏概全（病鸡当代表）
 → 【收束】「唯一真正需要改变的，其实只是自己的心态」→ 心无外物 / 平常心就是道 / 心乱在尘世、心静在禅中【关键转折】
```

**关键前提**：①故事中禅师的反问具有普遍有效性，可以从个别场景推广到日常；②「心」是足够自足的解释项，外部环境与结构因素不必单列；③点题句与故事之间的类比是恰当的。三条前提本书均未论证，而是靠**反复出现、不加反例**来建立可信感；这既是它易读的原因，也是它的主要软肋。【推断】

## 9. 可迁移模型/行动清单

**模型 A：「三步点题单元」**——把任何一则修养故事拆成：①**场景**（谁、在什么具体处境）→ ②**反转**（一句反问，把归因从外拨回内）→ ③**命题**（一句可复述的结论）。读时只记第 ③ 句，用第 ① 句回忆，用第 ② 句检验自己是否又在向外归因。

**模型 B：「向内转四问」**——遇到困境依次问：①我是不是把原因放在了命数／他人／环境？②我此刻能改变的最小一件事是什么？③我是不是「意念过重」（求全求快）而该降低起步底线？④我是不是在用一杯水装一匙盐（心量太小）？

**模型 C：「强度—节制双轴」**——本书看似矛盾的两组命题其实分属两轴：**方向轴**要「渴求强烈、全心全意」，**节奏轴**要「底线越低越好、循序渐进」。用双轴而非单轴读，可避免把「精进」读成「急切」。

| 步骤 | 操作 | 判断标准 | 边界 |
|---|---|---|---|
| 1 归因 | 写出自己给出的第一个解释 | 是否全在外部 | 外部原因未必不成立，本书只反对「由它主宰」 |
| 2 定目标 | 找「不动的大树」而非「会走的水牛」 | 目标是否稳定、正确、合理 | 稳定 ≠ 僵化，环境变了须复检 |
| 3 降底线 | 把起步量定到不易受挫的程度 | 能否持续而不伤勇气 | 低底线是起步策略，不是永久标准 |
| 4 用全心 | 一次只做一件，用「全部的心」 | 是否心无旁骛 | 与第 3 步并用，防止「既贪多又分心」 |
| 5 转苦 | 把已来的挫折改读为「留脚印的泥路」 | 是否减少了退缩 | 不主张自寻苦，也不适用于结构性不公 |
| 6 扩心量 | 把「一匙盐」放进更大的容器 | 烦恼浓度是否下降 | 心量替代不了必要的边界与申诉 |

**行动清单**：① 归因先查「是不是在向外求」；② 目标选「不动的」；③ 起步宁低勿高；④ 用心宁专勿散；⑤ 逆境不急着消除，先问「它锤炼了什么」；⑥ 被冒犯时先算「生气能否使眼镜复原」；⑦ 评价他人前先问「我是不是拿病鸡当了代表」；⑧ 对「平常心」「顺其自然」保留一问：它是否会被用来回避本该处理的问题。【推断】

## 10. 局限与争议

1. **以寓言代替论证**：全书论据几乎全是无出处、无年代、无可核验的对话体故事，结论靠「情理上像真的」与反复出现建立；「释迦牟尼说」「大梵天来到他面前」等属叙事设定，不宜当作史实用。【推断/外部通识】
2. **命题间未排序、未处理冲突**：「心生的意念不要过重」与「渴求强烈才能心无旁骛」「志乃心生，更需全心全意」并列出现却无协调说明；「顺其自然是最好的处事方式」与「勇猛精进」「要能忍受不寻常的锤炼」之间也存在张力，须读者自行补判准。【原文·目录；争议为推断】
3. **「向内转」的过度归因风险**：「并不是你所遇到的环境使你受到了挫折，而是由于你对各种情况的想象」「你还带着你的所有麻烦的根源——也就是你自己」把因果几乎全数收归个人心境，对制度性、结构性、他人造成的实际伤害缺少讨论，可能被误用为「受害者自责」。【推断】
4. **宽容命题的边界未系统化**：盘珪禅师不罚行窃者、清心禅师「我的头硬如石头」被推为普遍教育法则，但素材未讨论「反复越界且无改意」「涉及安全与权利」时是否仍应宽容；仅「心怀一颗公正的心」一篇触及「不可以偏概全」，未形成判准。【推断】
5. **人物与出处的不可考**：慧远、盘珪、仪山、清心、恒远、玄真、禅海、南泉、玄觉、广圄、从心等名号散见各篇，书内未标经典出处与传承；本笔记一律按书内称呼记录，**不指认任何公案出自《五灯会元》《景德传灯录》等典籍**，亦不作历史真实性判断。【材料不足】
6. **编次与重复**：目录「漫谈消费」式重复现象在本书亦见（目录与正文标题重复计入 139 个），「一切都在自己的手中」「以坦然的心看待他人的品评」等分段首尾出现标题串并列，疑为抽取或排印导致；实际篇目数、是否有分辑**材料不足**。【原文·章节结构；推断】
7. **阅读局限声明**：本笔记依据自动抽取素材，可读到约 30 余篇的完整或近完整故事；目录后半「无常之中有平常」之后的多数篇目仅见标题，未见正文，故第四组「心的转化」的概括主要依据标题与金句候选，**待核**。【阅读局限】

| 4 | 主旨 | 「一切都在自己的手中」与「外在的帮助固然重要」是否矛盾？ | 不矛盾：本书否定的是「由外在主宰」，不是否定外在帮助本身；前者立主体性，后者是明确留出的限定 |
| 5 | 论证 | 「卖石头」与「一斤米」两则如何共同支撑「价值由自我认定」？ | 二者同构：对象未变（米还是那斤米／石头还是那块石头），估价随观看者而变；故评价差异不说明对象价值，而说明「看」的位置；但故事随后都落到行动（小和尚静心做事而成禅师），说明自我认定是起点非终点 |
| 6 | 论证 | 「逆境是必要条件」这命题靠什么成立？ | 靠三则反转性例证：无风雨的麦子不结实、干硬路留不下脚印、石阶受不了敲打而不能成佛像；共同结构是「去掉苦反而失去成果」。属类比论证，非因果证明 |
| 7 | 反例 | 「心生的意念不要过重」会不会推翻「渴求强烈才能心无旁骛」？ | 不推翻，二者分属两轴：前者管节奏（起步底线要低、循序渐进，避免求全求快而受挫），后者管方向（专注到「只想得到空气」）；但本书未明说这一区分，是读者须补的判准 |
| 8 | 反例 | 「并不是环境使你受挫，而是你对情况的想象」有没有适用边界？ | 有。作为心境调节有效，但把因果全收归个人，对制度性、结构性或他人造成的实际伤害缺少讨论，可能被误用为自责或回避必要的外在改变；本书自身亦承认「外在的帮助固然重要」 |
| 9 | 应用 | 用「三步点题单元」拆解一则你读过的劝诫故事，并判断它是否跳过了论证。 | ①场景 ②反转反问 ③可复述命题；检验：反问是否真的排除了其他解释？命题是否超出场景允许的范围？结论是否只靠「像真的」？ |
| 10 | 应用 | 把「一匙盐」模型用于一次真实的情绪事件，并指出它的限度。 | 操作：把烦恼（一匙盐）放进更大的心量/时间尺度（一盆水、更大的空间），浓度下降；限度是它改变的是感受强度而非事实，不能替代必要的边界设定、沟通或申诉，也不能用来要求他人「大度」 |

## 13. 三档压缩版

**100 字版**：智缘《心生菩提树》是数十篇「格言标题＋禅门寓言＋结尾点题」连缀而成的修养故事集。它反复把困境的归因从命数、吉相、奇迹、环境与他人评价拨回「自己的心」：价值由自我认定（一斤米、卖石头），外求无效（扮吉相、求奇迹），苦是成就的必要条件（麦穗空瘪、雨后泥路），宽容是更有效的影响（不生气、不逐偷窃者）。落点是「要改变的只是自己的心」。

**300 字版**：本书不立体系、不引经据典，而以同一套「故事—反转—点题」单元反复变奏，回答一个日常问题：人把困境归给命数、环境、他人时，怎样把注意力拨回自己？前半立主体性：插秧要盯不动的大树而非会走的水牛，起步「底线越低越好」、循序渐进；一斤米在炊妇与制酒商眼中价差数十倍而「米还是那斤米」，同一块石头被认作压纸石、化石、和氏璧而不自知，故「你究竟有多大出息，取决于你到底怎样看待自己」；算命、扮吉相（牛黄、毗勒果「不能自救」）、求奇迹（「除了你自己以外，世界上根本没有其他的什么可以称为奇迹」）逐一破产，归结为「求人不如求己」「只有自己才能真正地主宰自己」。中段反转条件：求来一年无风雨的麦子「长得又高又好」却颗粒无收，又干又硬的路留不下脚印，石阶质问佛像，答「谁叫你当初受不了苦，没敲几下就哇哇叫呢！」——苦被改写为锤炼。后段把「向内转」推到人际：慧远法师眼镜被撞碎而不生气（「生气既不能使眼镜复原」），盘珪禅师两度不罚行窃学生「因为他需要我的教诲」，一匙盐在一杯水咸、一盆水则不咸，养鸡场主人拿「病鸡当代表」被反问「也同样太不公平了吧」。全书收于「心乱只是因为身在尘世，心静只是因为身在禅中」。它易读、可跳读，但论据全为无出处的寓言，命题间（意念勿重／渴求强烈、顺其自然／勇猛精进）未排序也未协调。

**800 字版**：《心生菩提树》（智缘，元数据 publisher 标 COAY.COM，全文字数约 50484 字）是一本以故事载道的心灵修养读物。它没有序言可据、没有章节层级、没有概念定义，也不标明任何公案的经典出处；素材识别到 139 个标题（含目录与正文重复），实际篇目为数十篇，每篇几乎都是同一个模具：一个格言式标题（标题本身就是命题），一则白话对话体禅门故事，末尾一段以「因此／可见／生活中」起头的点题议论。这种高度同构的模块化结构决定了它的身份——不是佛学理论、不是公案汇编、不是高僧传记，而是**同一命题的多故事变奏**；删去若干篇并不影响主线，读者可以从任何一页开始。书名「心生菩提树」已点明取向：觉悟之树不长在外边，而长在心里；全书反复回到的圆心正是「要想改变世界，必须先改变自己」「要改变的只是自己的心」。前段先确立主体性。「找到适合自己的人生轨迹」里，弟子插秧盯住吃草的水牛，秧插成一道弧线，改盯远处不动的大树便插直了，点题是「做事要选定目标，但如何选择目标，选择怎样的目标也是关键」；紧接着「心生的意念不要过重」又给这股进取心装上刹车——小和尚想把摊上的鱼全捞来放生，「一连捞碎了三张网，连一条小鱼也没捞到」，高僧的劝法是「一般来说，越低越好，因为低的目标容易实现，人的勇气不容易受到挫伤……循序渐进，自然会挑得更多、挑得更稳」。价值由谁定，是前段最着力的一组：「自己就是一把标尺」中，同样一斤米在炊妇眼中「不过能做两三碗米饭」、农民「最多值一元钱」、卖粽子的可卖三元、制饼者五元、制酒商勾兑后「能卖 40 元钱」，而「米还是那斤米」；「一切都在自己的手中」一组里，小和尚奉老和尚之命把一块石头先后拿到集市、米铺、珠宝店，且每次都被叮嘱「无论别人出多少钱都不要卖」——妇女出到六文想买去压纸，米铺老板认出是化石愿出五百两，珠宝店老板「愿意拿我所有的财产来换」，因为「它只是外面包裹了一层石头的样子，里面是一块无价的宝玉，就好像古代的『和氏璧』一样」；点题是「人也是一样，都有着各自独特的价值所在……要认识到自身的价值，挖掘内在的宝藏」。与「向内定价」配套的，是对「向外求」的连番拆解：年轻人因棉花霉烂、饭店失火、父母病故而去算命，得句「命数注定，他一辈子都不会有发迹之日」便彻底颓废，故事给出的反题是「命运其实就像这粒葡萄一样，就在你自己的手中啊！」；「生命由自己主宰」里施主用杨枝漱口、牛黄涂额、头顶贝壳、手举毗勒果「扮吉相」，修行僧逐一追问牛黄从何而来、毗勒果如何被石头打落、枝叶「被做成柴薪燃烧而不能自救」，逼出「这世上根本没有一个外在的可以主宰吉凶的东西」，但仍补一句限定「外在的帮助固然重要，但只有自己才能真正地主宰自己」；「心的力量是无穷的」里，求奇迹者等了许多天质问佛祖，得到的回答是「除了你自己以外，世界上根本没有其他的什么可以称为『奇迹』……与其求佛祖给你奇迹，不如自己给自己奇迹」。信心的效力也被正面立起：信徒听船夫说恒河「很浅而已，差不多到膝盖」便从水面走过，众人惊以为菩萨示现，释迦牟尼解释「他跟你们一样，只不过他对我所说的办法有绝对的信心」；又老又丑又病、被丈夫打、被儿女弃、摔断腿的老妇出家后「扶着墙壁一直观照」，「凭着无比坚定的意志力，她两个星期就得道了」。中段把「苦」从障碍反转为条件：婆罗门求大梵天免去旱涝，一年「没有狂风暴雨，没有电闪雷鸣」，麦子「长得又高又好，但是……麦穗里什么都结不出来」；「改变环境靠聪明，改变心境靠智慧」里，玄真大师做了两年最苦最累的行脚僧、攒下一堆破瓦鞋而觉得不公，住持带他雨后走黄土坡，问「又干又硬」的路上能否找到脚印、泥泞的路上能否找到，他「愣了一下，然后马上明白了」，点题「不经历一定的磨炼，就像行走在又干又硬的地面，是不会留下痕迹的……雨后的花朵才更娇艳」；全书结尾更以石阶质问佛像「你资质比我差，条件没我好，却能享尽人间的礼赞和尊崇，我却每天遭受凌辱践踏」、佛像笑答「谁叫你当初受不了苦，没敲几下就哇哇叫呢！」收束，明说「要想有所成就，就要能忍受不寻常的锤炼」。后段把「向内转」推到人际与心量：慧远法师被大汉撞碎眼镜、戳青眼皮而不生气，理由极实用——「生气既不能使眼镜复原，又不能让脸上的淤青消失」，且「生气只会扩大事端」，多年后对方寄来五千元谢恩并求祈福消业；盘珪禅师面对学生行窃，两次不罚，甚至在众人联名威胁「集体离开」时仍说「你们都能够明辨是非，这是我感到欣慰的……可是我不能不管那个行窃的学生，因为他还不能明辨是非，如果我不来教他，那谁来教他呢？」偷窃者「感动得热泪盈眶……从此以后再也不偷别人的东西了」；「心存一颗包容的心」用一匙盐放入一杯水「咸」、放入一盆水「感觉不到咸味」、再推问「如果投放在更大更广的空间呢」，把宽容讲成心量的函数；仪山禅师因弟子倒掉洗澡剩水而斥「就是一滴水……价值也无限地大」，弟子改名「滴水」，后答「世间上什么功德最大？」「滴水！」；养鸡场主人因讨厌沙弥而散布坏话，两个沙弥偏挑秃头跛脚的病鸡，说要「拿它对外当代表」，主人抗议「对我实在太不公平了」，得到的回敬是「少数几个沙弥行为不检点，你却喜欢拿他们来当代表，对我们来说，也同样太不公平了吧？」——反对以偏概全。最终收束于「心乱只是因为身在尘世，心静只是因为身在禅中，没有中断就没有连续，没有来也就没有去」，以及「平常心就是道」「心无外物才是超然的境界」等后段标题。读本书须守四条边界：其一，全部论据都是无出处、无年代、无可核验的寓言，说服力来自「情理上像真的」与反复出现，而非事实或逻辑；其二，命题之间既未排序也未协调——「意念不要过重」与「渴求强烈」「全心全意」、「顺其自然」与「勇猛精进」并列而须读者自行分轴（方向要强、节奏要缓）；其三，「并不是你所遇到的环境使你受到了挫折，而是由于你对各种情况的想象」这类句子把因果几乎全数收归个人心境，对制度性困境与真实的伤害缺少讨论，用作自我调节可以，用作评判他人则失当；其四，素材中后半部分多数篇目仅见标题，第四组的概括有待核对全文，且作者生平、出版年、公案出处均材料不足，不宜替它补任何经典来源。
