在 Vue 3 中使用`<iframe>`显示 PDF 文件时，本地文件能够正常显示，但通过网址访问时却触发下载而不是直接预览，这通常是由于以下原因导致的：


1.MIME 类型问题
当服务器返回的文件 MIME 类型不正确时，浏览器可能无法正确识别文件类型，从而触发下载行为而不是直接预览。


解决方法
确保服务器正确设置了 PDF 文件的 MIME 类型为`application/pdf`。如果 MIME 类型不正确，浏览器会将其视为普通文件并触发下载。


• 检查服务器配置
如果你使用的是 Apache 服务器，可以在`.htaccess`文件中添加以下配置：

```apache
  AddType application/pdf .pdf
  ```


如果你使用的是 Nginx，可以在配置文件中添加：

```nginx
  types {
    application/pdf pdf;
  }
  ```



• 检查后端代码
如果你通过后端动态提供 PDF 文件，确保在响应头中正确设置`Content-Type`：

```javascript
  res.setHeader('Content-Type', 'application/pdf');
  ```



2.浏览器安全限制
浏览器对跨域资源的访问有严格的安全限制。如果 PDF 文件和你的 Vue 应用不在同一个域下，浏览器可能会阻止直接预览。


解决方法

• 使用代理
如果 PDF 文件和 Vue 应用不在同一个域下，可以通过设置代理来解决跨域问题。在 Vue 3 项目中，可以在`vite.config.js`或`vue.config.js`中配置代理：

```javascript
  // vite.config.js
  export default {
    server: {
      proxy: {
        '/pdf': {
          target: 'https://example.com', // PDF 文件所在的服务器地址
          changeOrigin: true,
        },
      },
    },
  };
  ```


然后在 Vue 组件中使用代理路径：

```javascript
  const pdfUrl = '/pdf/path/to/your/file.pdf';
  ```



• 确保同源策略
如果可能，将 PDF 文件和 Vue 应用部署在同一个域下，这样可以避免跨域问题。


3.PDF 文件的 URL 问题
如果 PDF 文件的 URL 是一个直接的文件下载链接（例如，通过 PHP 脚本提供文件下载），而不是一个可以直接预览的链接，浏览器会触发下载行为。


解决方法
确保 PDF 文件的 URL 是一个可以直接访问的链接，而不是一个触发下载的脚本。例如：

• 直接链接

```html
  <iframe :src="'https://example.com/path/to/your/file.pdf'" frameborder="0"></iframe>
  ```



• 避免触发下载的脚本
如果你必须通过脚本提供 PDF 文件，确保脚本返回正确的`Content-Type`和`Content-Disposition`：

```php
  header('Content-Type: application/pdf');
  header('Content-Disposition: inline; filename="yourfile.pdf"');
  readfile('path/to/your/file.pdf');
  ```



4.浏览器插件或配置问题
某些浏览器插件或配置可能会干扰 PDF 文件的预览。


解决方法

• 检查浏览器插件
禁用可能干扰 PDF 预览的浏览器插件。

• 测试其他浏览器
在不同的浏览器中测试，确保问题不是特定于某个浏览器。


5.示例代码
以下是一个完整的 Vue 3 示例，展示如何正确使用`<iframe>`预览 PDF 文件：


```vue
<template>
  <div>
    <iframe :src="pdfUrl" frameborder="0" width="100%" height="800px"></iframe>
  </div>
</template>

<script>
export default {
  data() {
    return {
      pdfUrl: 'https://example.com/path/to/your/file.pdf', // 确保这是正确的 PDF 文件链接
    };
  },
};
</script>
```



总结
如果本地文件可以正常显示，但通过网址访问时触发下载而不是预览，可能是以下原因之一：

• MIME 类型不正确：确保服务器返回的 MIME 类型为`application/pdf`。

• 跨域问题：通过代理或确保同源策略来解决跨域问题。

• PDF 文件的 URL 问题：确保 URL 是一个可以直接访问的链接，而不是触发下载的脚本。

• 浏览器插件或配置问题：检查浏览器插件或配置。

通过以上方法，可以解决通过`<iframe>`预览 PDF 文件时触发下载的问题。
