今天，我们将介绍七个对开发 3D 项目至关重要的工具和网站。这些资源来自最近发现的网站 Three.js Resources。该网站汇集了专为 Three.js 设计的各种工具，你可以按类别搜索，甚至可以提交尚未收录的新资源。将所有资源集中在一处的便利显而易见，请坚持读到最后，因为最后两个工具会让你惊叹不已。

#### https://threejsresources.com

### 1. Three.js 学习课程


首先，我们来谈谈学习 Three.js 的课程。如果你刚入门，还不确定如何开发 3D 项目，一门全面的课程可能正是你需要的。在众多在线课程中，“Three.js Journey”尤为突出。它涵盖了从基础到高级概念（如着色器），还包括专门介绍 React Fiber 的章节。还有专注于着色器的课程，以及 Wawa 在其 YouTube 频道和网站上分享的 React Fiber 教程。

#### https://threejs-journey.com/

### 2. React Fiber 库

![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/9Z5K66tFPiazkvia5CnebGbnibDSgptCh818fQPp7aHGS8hqS5ia3rrVW4QAq5cSwCsI942IOy4lLoN6xR9BQH1BhA/640?wx_fmt=png&from=appmsg&watermark=1&tp=wxpic&wxfrom=5&wx_lazy=1#imgIndex=2)

React Fiber 是专为 React 打造的 Three.js 库。如果你使用 React 或 Next.js 开发项目，Fiber 是创建 3D 场景的理想选择。它提供了许多预实现的特性和钩子，便于与 3D 场景交互，充分利用 React 的响应式和用户交互优势。

#### https://r3f.docs.pmnd.rs/getting-started/introduction

### 3. 物理库

![图片](https://mmbiz.qpic.cn/sz_mmbiz_jpg/9Z5K66tFPiazkvia5CnebGbnibDSgptCh81BmaBetLbiaLeYIkmmicncrPpCbVdn8Fo818uwrhaoqEC4qoBhIaV5bxw/640?wx_fmt=webp&from=appmsg&watermark=1&tp=wxpic&wxfrom=5&wx_lazy=1#imgIndex=3)

在 3D 游戏开发中，管理碰撞、力、引力等物理效果至关重要。这个资源门户提供了多种物理库，包括 Cannon.js 和 Rapier。Cannon.js 使用简单，但更新频率较低。而 Rapier 功能强大，尽管较为复杂。

#### https://rapier.rs/

### 4. 3D 模型和贴图

![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/9Z5K66tFPiazkvia5CnebGbnibDSgptCh81ToQRiaCSicAKfoOmWFLqspu0hozOZQbsxO08uHvRqjqRRFATJ0xfC99A/640?wx_fmt=png&from=appmsg&watermark=1&tp=wxpic&wxfrom=5&wx_lazy=1#imgIndex=4)

在 3D 项目中，你经常需要模型或贴图资源。这个门户网站列出了大量提供免费和付费资源的网站。使用时务必注意许可条款。Sketchfab 和 Poly Pizza 是下载 3D 模型的热门选择。此外，还有专门提供实现照片级真实感所需的贴图和材质的网站。

#### sketchfab.com

### 5. 3D 建模软件

![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/9Z5K66tFPiazkvia5CnebGbnibDSgptCh815OofDdvibXwj7WnaDBlZiblXsv4gFibbOOfvCtXMzkN7Qs54fjYvwHJBw/640?wx_fmt=png&from=appmsg&watermark=1&tp=wxpic&wxfrom=5&wx_lazy=1#imgIndex=5)

如果你更喜欢自己创建模型，掌握 3D 建模软件必不可少。Blender 和 Cinema 4D 众所周知，但 Spline 作为一款免费的网页端工具尤为突出。Spline 允许你从零开始创建 3D 场景或使用预设模板，并能无缝集成到 Three.js 和 React Fiber 中。

#### https://spline.design/

### 6. 动画工具

![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/9Z5K66tFPiazkvia5CnebGbnibDSgptCh814v9ibWygN3UBbRg1mGxX3fFeHOjiacNd5ibO4owiagUSg6AmoyRwXiaTI9w/640?wx_fmt=png&from=appmsg&watermark=1&tp=wxpic&wxfrom=5&wx_lazy=1#imgIndex=6)

动画是打造引人入胜的 3D 项目关键。像 GSAP 这样的库可以动画化 DOM 元素和场景中的 3D 对象。但这里的亮点是 Theatre.js，它提供了一套动作设计工具库。Theatre.js 就像一个导演套件，允许你通过图形界面精确地为场景中的相机和对象制作动画。

#### https://www.theatrejs.com

### 7. 着色器调试：Spector.js

![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/9Z5K66tFPiazkvia5CnebGbnibDSgptCh81n834Zia1Px373uUrSz6D1WvF9D9tHhNgNgzN6jLmKhw36XezSzm1deg/640?wx_fmt=png&from=appmsg&watermark=1&tp=wxpic&wxfrom=5&wx_lazy=1#imgIndex=7)

最后一个也是最令人兴奋的工具是 Spector.js，它是一款终极浏览器扩展，可用于检查你访问网站上的着色器。在使用 Three.js 和 WebGL 时，由于一切都在画布上渲染，调试并不直观。Spector.js 让你直接在浏览器中查看专业人士使用的 GL 代码和着色器。

#### https://chromewebstore.google.com/detail/spectorjs/denbgaamihkadbghdceggmchnflmhpmk
