### 路径

```
const filePath = path.join(__dirname, "../dist/index.html");
const exePath = path.join(process.resourcesPath, "recordingWave.exe");


path.join  ：这是 Node.js 的   path   模块提供的一个方法，用于将多个路径片段连接成一个完整的路径。它会根据操作系统的路径分隔符（Windows 是   \  ，其他系统是   /  ）自动拼接路径。

__dirname   是 Node.js 中的一个全局变量，表示当前执行脚本所在的目录路径。它是一个绝对路径，指向当前文件所在的目录。
   
process.resourcesPath 指向应用的   resources   文件夹的路径。在打包后的 Electron 应用中，  resources   文件夹通常位于应用的根目录下,


```

```
1. fs模块
fs是 Node.js 的文件系统模块，提供了用于读取、写入、修改文件的 API。• 它可以同步或异步地操作文件。

1.   fs.writeFileSync   方法•   
   fs.writeFileSync   是一个同步方法，用于将数据写入到文件中。
   它的语法是：javascriptfs.writeFileSync(path, data[, options])
   path  ：文件路径，可以是字符串、Buffer 或 URL。
   data  ：要写入文件的内容，可以是字符串或 Buffer。•   
   options  ：可选参数，用于指定写入文件的编码、文件标志等。常见的选项包括：•   encoding  ：指定文件的编码，默认是   utf8  。•   mode  ：指定文件的权限，默认是   0o666  （即   rw-rw-rw-  ）。•   flag  ：指定文件的打开模式，默认是   'w'  （写模式，如果文件已存在则覆盖）。
```
