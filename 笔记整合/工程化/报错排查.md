## cd() never called!

> 来源：有道云笔记
> 原路径：`BUG/cd() never called!.md`

1.执行cmd命令行不要再vscode里执行，因为哪个不一定是管理人员模式打开的。2.用管理员身份打开cmd命令行，目录定位到程序的文件上，随后执行npm cache clean -f清理一下。3.随后再执行一下npm install它就成功了，而且正常下载，最后再执行一下npm run dev ，项目正常运行，OK了。
说明还是得要管理人员的模式才能正常运行，为什么呢？因为我用不是管理人员的方式运行的时候是失败的，是有权限问题。。。。

## events.js292

> 来源：有道云笔记
> 原路径：`BUG/npm node/events.js292.md`

删除node_modules和package-lock.json，重新安装依赖。
npm install 成功之后再次启动 npm start

可以删除依赖后重新下载，node版本也不要太低，mac可以用户nvm来管理node版本.还有就是建议不要用 cnpm 安装 会有各种诡异的bug 可以通过如下操作解决 npm 下载速度慢的问题

npm cache clean --force
rm -rf node_modules
rm -rf package-lock.json
npm install
```
npm install --registry=
npm install --registry=
```

## PostCSS received undefined instead of CSS string

> 来源：有道云笔记
> 原路径：`BUG/npm node/PostCSS received undefined instead of CSS string.md`

卸载当前版本的node-sass和sass-loader,因为版本和当前的不兼容,安装对应版本的包即可。
安装其他版本
如果 不成功的话可以试一下cnpm
解决后可以尝试npm run serve

## 安装依赖报错node-sass@6.0.1 postinstall `node scriptsbuild.js`

> 来源：有道云笔记
> 原路径：``BUG/npm node/安装依赖报错node-sass@6.0.1 postinstall `node scriptsbuild.js`.md``

在当前目录下进行 node-sass 的数据源没设置：
1.npm config set sass_binary_site=
2. 执行  npm install node-sass
3.npm run dev 重启项目成功
node-sass@6.0.1 postinstall: `node scripts/build.js`
https://npm.taobao.org/mirrors/node-sass

## 微信单页面展示

> 来源：有道云笔记
> 原路径：`BUG/微信单页面展示.md`

1 发布时确保请求模块已经配置（本地/测试/生产）
2 单独写在外面，不用和项目页面写在一个文件夹。pages/views.....main.js
3，在根目录public 文件夹 创建 同名examination.html文件。
4 二维码分享 时 对于微信需要 encodeURIComponent()进行转码 不能只对汉字转转对象 加JSON.stringify(obj)
